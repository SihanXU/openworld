欢迎来到 OpenWorld 中文维基

OpenWorld 是一款在网页上直接玩的 2D 像素角色扮演游戏。世界的状态和规则都是代码：游戏本身完整、可以从头玩到尾；玩家做了世界从没见过的事，世界会学会，并且记住（见世界会学）。

你从云顶台地醒来，身边多了一个小精灵露米。白昼一天天变短，极夜正在回来。五苦圣教召你踏上朝圣之路，去找五位持印者。

本站同时是游戏的企划案：做好了的写它现在的样子，定了没做的标「规划中」，没定的标「待设计」。 · 进入游戏 · 新手指南 · 参与编辑

最近在做的

  • 第一章（第一印·荆棘冠）已经可以从头玩到章末；后面四印的章节还在待设计。
  • 誓守之地成了能干活的营地：阿尔贝里克的货摊和晨辉币（见金钱），钓鱼，喂养、挤奶和繁殖，再加十种作物。
  • 二十个主动技能，左下角的技能栏（Shift+1–6）和技能面板（U）。
  • 新手教程：一课一个动作，没教的键锁住。
  • 楼层：每层只建本层，天花板是唯一的例外。

完整的改动记录见版本历史，维基自身的改动见特殊：最近更改。

参与编辑

本站的每一页都是 GitHub 仓库里 wiki/pages/ 下的一个文件，项目组的每个人都能改，合进主线后网站自动更新。从编辑入门开始；写法见格式手册和风格指南；还没写完的页面见特殊：待完善。
