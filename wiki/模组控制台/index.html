模组控制台

来自OpenWorld 中文维基 · 玩法
开发者功能：只在开发版里有，正式游戏里没有。

模组控制台是给开发者看的窗口，只在开发版里有，正式发布的游戏里没有。它列出世界遇到的每一个未定义的事件，显示 AI 会收到的请求，并且允许人手写一个补丁。手写的补丁和 AI 写的走同一套检查、应用、保存的流程，所以没连 AI 时也能用它教世界新东西。

打开

  • 按 `（数字 1 左边的键）打开或关上。
  • 或者在选项里点“模组控制台（开发）”。
  • 点 ✕ 或按 Esc 关上。打开时时间暂停。

顶栏右侧显示 AI 服务的状态：连上时是“● 模组师：模型名”，没连上时是“○ 无模组师：手动打补丁”。

四个分页

未定义

  • 左边从新到旧列出世界遇到的未定义事件，每条前面有一个状态：pending（等待中）、patched（已学会）、fallback（按默认处理了）、rejected（补丁被拒）。
  • 选中一条，右边显示它是什么事件、发生在第几刻、哪张地图、几点，以及发给 AI 的完整请求。
  • 下面是一个文本框，用来写补丁：
    • 填入模板：填入一个补丁的起点：宿主是这条事件的宿主那一种东西（确切的种类），事件类型、空缺（hole）和位置（at）按这条事件填好，再加一个看得见的结果、几处待填的说明，和这次事件作为测试；
    • 复制为 LLM 提示词：把这次请求连同规范复制成一段可以直接交给大模型的提示词；
    • 什么也不发生：只在事件还在等待时出现，直接按默认处理；
    • 校验并应用：检查补丁，通过就立刻生效。结果显示“✓ 校验通过并已应用”，或者列出错误和警告。

手写的补丁和 AI 写的一样，只属于一种东西、只填一处空缺（见一条规则管一种东西的一处空缺）：

  • 宿主必须正好是 {"type": 种类}，不能写标签或一整类；要分情况，写在规则的树里。
  • on 必须是确切的事件类型，不能是一个大类。
  • 必须写 hole（填的是哪一处空缺）；at 是它在这一种东西的树里接在哪个空着的分支上（第一条回答是空）。
  • 不能写 inherit；每个 if 都要有 else；不回答的情况写成 {"undefined": true} 留空，以后再问。至少要有一处给出结果。
  • 对着选中的那条事件提交时，宿主、事件类型、hole 和 at 由游戏按那条事件填好，写成 inherit 或缺了 else 的分支也会被改成留空，所以手写时只需要写树。

规则库

显示规则库的版本号、基础规则的数量、补丁的数量和各类事件的规则数，下面逐条列出补丁：编号、事件类型、作者、时间，每条有一个 remove 按钮可以删掉它。

ModSpec

AI 写补丁时依据的完整规范：有哪些事件、效果、状态、地形和物品种类，以及写规则的守则。可以用 Copy JSON 复制下来。

世界

调试工具，加上世界的统计和性能数字（地图、人物、生物、物品的数量，每刻耗时，实体数，已加载的地图数，帧率）：

工具 作用
Give 按物品种类的编号（如 item/material/iron_ore）给自己一件东西，输入框会提示可用的编号
Teleport 传送到某张地图（不填就是当前地图）的某个坐标
Emberfall, by the lit forge 直接传送到余烬镇点着的熔炉旁
Set hour 把时钟拨到某个整点
召唤白骑士 在朝阳大道召唤白骑士·阿尔贝里克，用来反复测试首领战
开启第二部 · Open Part Two 设上事实 world.part2，打开第二部：朝阳大道往东去余烬镇的路、大地图上余烬镇一线的地点和主线任务屠龙之路

其他开发功能

  • 无敌：开发版里在浏览器控制台输入 lsw.god() 开关无敌，或者在网址后加 ?god=1，打开时提示“无敌已开启（开发）。”
  • 指定 AI 服务：网址加 ?modder=地址 连到另一个 AI 服务，?modder=off 不连。开发版默认连本机的服务。
  • 预取：网址加 ?prefetch=1 后，鼠标在一个带「?」的动作上停一会儿，游戏就会提前去问 AI。默认关闭，因为它会为玩家没真正做的动作消耗模型调用。
  • 首领 · 试战台：“首领挑战”所在的页面（boss-gallery.html）去掉 ?challenge=1 参数，就是开发用的首领测试台。见首领挑战。
  • 清理共享规则库：命令行里 npm run modder -- library prune 列出并撤回检查不再通过的补丁，比如 2026-10-09 以前按整类写的补丁，或者所在的空缺被游戏规则改掉了的补丁；AI 服务每次启动时也会这样清理一遍。npm run modder -- library 列出全部补丁，npm run modder -- library remove <编号> 删掉一条。
