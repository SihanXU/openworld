编辑入门

来自OpenWorld 中文维基 · 帮助

欢迎来编辑 OpenWorld 维基。本站的每一页都是 GitHub 仓库 SihanXU/symbolic-world 里 wiki/pages/ 下的一个文件，项目组的每个人都能改。改动合进主线（main）后一两分钟，网站自动更新。

改一页

  1. 在网站上打开那一页，点右上角的「编辑」。会跳到 GitHub 上这个文件的编辑页（需要登录 GitHub，并且是仓库的协作者）。
  2. 直接改文字。格式见格式手册，写法见风格指南。
  3. 页面底部填一句改了什么，然后：
    • 小改（错字、补一句、改个数字）：选「Commit directly to the main branch」，直接提交。
    • 大改（重写一节、改结构、新的设定）：选「Create a new branch … and start a pull request」，开一个合并请求，等别人看过再合。

提交后，仓库的自动检查会构建整个维基。链接写错、模板写错时检查会失败，并在合并请求里告诉你哪一行有问题。

新建一页

  • 链到一个还不存在的页面时，链接是红色的。点红链，会打开 GitHub 的新建文件页，文件名和该类页面的骨架都已经填好。
  • 游戏里的每个人物、物品、怪物、地点、任务，网站都自动生成了一页（带「小作品」标记）。点这样的页面上的「编辑」，同样会新建对应的文件，骨架里已经包含该有的数据模板，补上文字就行。

讨论

每页右上角的「讨论」会开一个 GitHub 议题（带 wiki 标签），标题是页面名。以下情况先讨论再动手：

  • 改一类页面的结构或模板；
  • 写还没定下来的设定或剧情；
  • 删除页面或大段内容。

本地预览

装好依赖（npm install）后，在仓库根目录运行：

npm run wiki
浏览器打开 http://localhost:5180/wiki/。改了 wiki/pages/ 里的文件，刷新页面就能看到。只想检查有没有错：

npm run wiki:check

自动生成的部分

信息框、表格、日程、对话、配方这些内容是构建时从游戏代码读出来的（见数据模板）。它们错了，要改的是游戏代码，不是维基页面。改游戏代码的人提交后，维基会跟着更新。

完备性

游戏里每样东西都必须有页面，每个系统都必须有说明。构建时会检查：游戏数据里的每个人物、物品、怪物、首领、地点、任务、技能分支、配方、状态，以及操作里的每个按键和每个面板，都要有对应的页面或小节。游戏加了新东西而维基没跟上，构建会报出来，列在特殊：待完善。

英文版

本站有英文版（English，网址 /wiki/en/…），是中文版的译本：中文是源头，大家照常用中文写。英文的每一页是 wiki/en/pages/ 下和中文页面同一路径、同一文件名的文件，开头的 source: 记着它译自中文的哪个版本。

  • 中文页面改了以后，英文页面顶上会自动出现「中文版已经改过」的提示，列在英文版的 Special:Completeness 里；不会让构建失败。
  • 还没有译文的页面，英文版照样有：游戏对象的页面显示英文的数据表，其他页面显示中文原文，并给出「Translate」按钮。
  • 改完一页的译文后，在仓库根目录运行 npm run wiki:translate -- stamp <英文文件>，记下它对应的中文版本。npm run wiki:translate -- status 列出没译和过时的页面。
  • 译文里的链接和模板参数可以照抄中文（[[露米]]、{{物品|木头}}），构建会找到对应的英文页面；npm run wiki:translate -- relink <英文文件> 会把它们改写成英文。模板也有英文名（{{infobox}} 就是 {{信息框}}），见格式手册。
