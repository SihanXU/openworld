本页按先后顺序列出世界观里的事件。设定原文大多不给具体年份，这里只写原文和游戏文字里说到的时间；说不准的写「不详」，没有定的写「待设计」。涉及反转的事件放在剧透块里。

游戏里的文书用「五苦纪元」纪年（森林里那张旧朝圣令落款「五苦纪元第380年」），纪元从哪一年算起没有说明。

## 第一次极夜

| 时间 | 事件 | 出处 |
|---|---|---|
| 几百年前 | 原夜渗入现实：太阳逐渐消失，白昼越来越短，直到世界陷入长夜。作物枯死，野兽异变，亡者不得安息。这就是第一次[[极夜]]，游戏里叫「初夜」。 | §1、§2 |
| 初夜之前或之时 | 一本历书写成，后来托宾把它卖给了奈莎（[[初夜历书]]）。 | 游戏文字；docs/chapter-1.md §7 |
| 第一次极夜中 | 人们试过战争、魔法、献祭、祈祷，都没能阻止它。 | §3 |
| 第一次极夜最严重时 | [[阿斯特拉]]出现，依次承受[[五苦]]：戴冠、受鞭、受饥、受钉、受枪。 | §1、§4 |
| 第五苦完成时 | 圣枪刺穿阿斯特拉的胸膛，太阳重新升起，极夜结束。 | §4 |
| 初夜之后的第一个黎明 | 人们在[[晨光丘]]顶的火坛借着晨光点燃初火，带下山去；那天早上礼拜堂的钟被敲响。[[初原村]]因这个黎明得名。 | 游戏文字（[[初晓礼拜堂]]、晨光石、守夜之备）；docs/chapter-1.md §1 |
| 之后 | 阿斯特拉的追随者建立[[五苦圣教]]，五件刑具被奉为至高圣物。 | §5 |

## 圣教的几百年

| 时间 | 事件 | 出处 |
|---|---|---|
| 不详 | 阿斯特拉一个人难以承担全部压力，教会建立[[持印者]]制度，把五件圣器的力量分给五位持印者。 | §6 |
| 不详 | 荆棘骑士团把自己的死者葬在[[荆棘谷]]地下。名册上有四十一个名字，最后一个是骑士长阿尔贝里克，「蒙圣城擢选，承戴荆棘冠」。他的兄弟托马斯修士被葬为守墓者，「看守此墓，直到夜晚归来」。 | 游戏文字（[[荆棘骸骨堂]]） |
| 不详 | [[芬尼克]]给阿尔贝里克当了六年侍从。冠冕交给阿尔贝里克后，他每年都少一点自己；一天早上他问芬尼克叫什么名字，芬尼克当晚离开。 | 游戏文字（芬尼克的回忆） |
| 五苦纪元第380年 | 初原村的卡西安修士被点名为朝圣者，在[[森林]]深处扎营，再也没有回来。伊尔丝说这是三十一年前的事。 | 游戏文字（[[上一位朝圣者]]） |
| 三十一年前 | [[赫斯珀]]开始看守渡口。 | 游戏文字 |
| 二十年前 | 教会解散[[灰烬守望]]，把最后几位修士定为异端。 | docs/chapter-1.md §5 |
| 二十年前 | 阿尔多和[[乔斯]]造了渡口的小桥。出钱的是一个穿灰衣的年轻人，付的是没有国王头像的旧钱币。 | 游戏文字 |
| 小桥造好的第二年春天 | 河水带走了阿尔多。 | 游戏文字（赫斯珀） |
| 第401年—第411年 | [[云顶台地]]观日哨记录仲夏日落：第401年 19:42，第405年 19:31，第409年 19:12。第411年，报告送下山后再没有回音。 | 游戏文字（[[守夜人的日志]]） |

| 不久前 | [[佩尔]]三次见到灰衣人，得到一块晚上会发热的石头。 | 游戏文字 |

| 不久前 | 白天太短，艾达的麦子死了；夜里的东西来了；谷仓着火那晚，一个灰衣人把她从烟里拉了出来。 | 游戏文字 |
| 游戏开始前不久 | 一场风暴在夜里扯断了渡口的渡绳。[[莉娜]]和[[奥斯卡]]躲进[[古墓]]，被困在里面；一个灰衣人从外面拉上了内门，又从门缝塞进一块面包。 | 游戏文字 |
| 游戏开始前 | 五苦圣教宣布五位持印者已经无法继续承担五苦，五印衰败，第二次极夜终将降临。 | §7 |
