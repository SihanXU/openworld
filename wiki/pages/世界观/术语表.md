世界观用语的一句话解释，按主题分组。解释只用第一层认知（游戏前期人人相信的说法）；会剧透反转的用语集中在本页最后的剧透块里。游戏里的系统用语（饱食度、传送雕像……）见各自的页面。

|---|---|---|
| 原夜 | 世界形成以前就存在的黑暗。太阳把光和它隔开。 | [[原夜]] |
| 极夜 | 原夜渗入现实、太阳消失、世界陷入长夜的灾厄。 | [[极夜]] |

## 信仰

| 用语 | 解释 | 详见 |
|---|---|---|
| 五苦圣教 | 阿斯特拉的追随者建立的宗教，游戏里的人常说「教会」。 | [[五苦圣教]] |
| 五苦 | 阿斯特拉承受的五种圣刑。 | [[五苦]] |
| 戴冠 | 第一苦：戴上荆棘冠。教会说是舍弃人的骄傲与意志。 | [[五苦#戴冠]] |
| 受鞭 | 第二苦：绑在刑柱上受鞭刑。教会说是以肉身偿还众人的罪。 | [[五苦#受鞭]] |
| 受饥 | 第三苦：断绝饮食，在天平上与粮食、罪与生命衡量。教会说是脱离肉身的欲望。 | [[五苦#受饥]] |
| 受钉 | 第四苦：钉在圣木上。教会说是接受死亡。 | [[五苦#受钉]] |
| 受枪 | 第五苦：圣枪刺穿胸膛。那一刻太阳重新升起。 | [[五苦#受枪]] |
| 五苦大礼 | 朝圣的终点：在圣城重新举行的五苦仪式。 | [[五苦#五苦大礼]] |
| 圣刑之器 | 五苦用过的五件刑具，教会的至高圣物。 | [[圣刑之器]] |
| 荆棘冠 | 第一件圣器，第一苦的刑具。游戏里是一件可以戴的物品。 | [[荆棘冠]] |
| 鞭刑柱 | 第二件圣器。 | [[圣刑之器#鞭刑柱]] |
| 饥刑之秤 | 第三件圣器。 | [[圣刑之器#饥刑之秤]] |
| 钉刑圣木 | 第四件圣器。 | [[圣刑之器#钉刑圣木]] |
| 穿心圣枪 | 第五件圣器。 | [[圣刑之器#穿心圣枪]] |
| 苦难并非神的遗弃 | 五苦圣教的核心教义的前半句，后半句是「苦难，是灾厄得以被偿还的证明」。 | [[五苦圣教#教义]] |
| 五苦纪元 | 游戏里文书使用的纪年。 | [[年表]] |
