---
类型: 系统
别名: 生命, 血量, HP, 心, 回血, 治疗
摘要: 快捷栏上方的十颗心：生命值怎样减少、怎样回复，生命上限怎样提高，归零后会怎样。
---
**生命值**显示为快捷栏左上方的十颗心。玩家开局有 40 点生命，每颗心代表生命上限的十分之一（开局每颗 4 点），按四分之一格画出，从右往左变空。鼠标停在心上会显示“生命 当前 / 上限”。生命归零时玩家倒地，出现死亡界面，见[[难度]]。

## 受到伤害

| 来源 | 说明 |
|---|---|
| 攻击 | 对方的攻击加上武器的威力，减去你的防御，至少 1 点。闪避（上限 50%）能让攻击完全落空，副手的盾牌按格挡率挡下攻击（上限 50%）。详见[[战斗]] |
| 元素 | 带元素的攻击还会按元素造成效果；元素抗性按百分比减少伤害。见[[元素]] |
| {{状态|燃烧}} | 身上着火时大约每秒掉 1 点，火会烧到旁边易燃的东西。变得{{状态|潮湿}}（淋雨、被泼水、走进泥潭）就会灭火 |
| {{状态|流血}} | 每秒掉 1 点，无视防御 |
| 摔落 | 落差一层以内不伤；每多一层掉 6 点。见[[楼层]] |
| 挨饿 | [[饱食度]]为 0 时每 8 秒掉 1 点，但不会扣掉最后 1 点 |
| 雷击 | 暴风雨时雷电会劈中附近的东西。见[[天气]] |

## 回复

| 方式 | 回复量 |
|---|---|
| 吃饱 | 饱食度在九成以上（18/20）且没满血时，每 8 秒回 1 点 |
| [[睡觉]] | 躺下时立刻回复缺少生命的一半；床在[[房间|卧室]]里则全部回满 |
| 疗伤温泉 | [[初原村]]的温泉：踏进去回 1 点，泡在里面时持续回血（{{状态|泡温泉}}） |
| {{物品|治疗药水}} | 16 |
| {{物品|解毒剂}} | 5 |
| {{物品|葡萄酒}} | 4 |
| {{物品|一杯麦酒}} | 3 |
| {{物品|浑浊药水}} | 1 |
| 喝水（{{物品|一瓶水}}、{{物品|水袋}}、一桶水） | 2，容器变空 |
| {{物品|一桶牛奶}} | 4，同时补 4 点饱食度，木桶变空 |
| {{物品|草药}} | 吃下回 4 点，同时补 1 点饱食度 |
| 复活 | 简单和普通难度复活后生命回满 |

- **普通食物不回血。** 面包、牛排这类食物只补[[饱食度]]，吃饱以后靠“吃饱回血”慢慢回来。见[[食物]]。
- 喝的东西和草药会先问“要喝掉X吗？”“要吃掉X吗？”，确认后才用掉。
- 拿着药水或饮料指着别人按 {{键|R}}，可以给对方喝，回复的是对方的生命。
- 营火不回血。

### 技能

| 技能 | 效果 |
|---|---|
| {{技能|自愈}} | 饱食度过半就会自动回血 |
| {{技能|再生}} | 饱食度只要不少于四分之一就会自动回血 |
| {{技能|肾上腺素}} | 受到攻击后生命不高于 30% 时，5 秒内每秒回 1 点，移动速度 +30%；每分钟最多一次 |
| {{技能|影中汲取}}（[[刺客]]） | 用匕首打倒敌人时回复生命上限的十分之一 |
| {{技能|奥术汲取}}（[[法师]]） | 用法杖打倒敌人时回复 3 点（魔杖不算） |

带“吸血”属性的武器和[[遗誓]]装备每次命中吸回生命，见[[装备]]。

## 生命上限

生命上限只能靠[[技能]]提高：

| 技能 | 生命上限 |
|---|---|
| {{技能|体魄}} | +4 |
| {{技能|强健}} | +6 |
| {{技能|钢铁意志}} | +8 |
| {{技能|不破之身}}（[[战士]]） | +10 |

学会时多出来的生命会立刻补上。心的数量始终是十颗，上限越高，每颗代表的生命越多。

## 归零

- 玩家生命归零时倒地，整个世界停住，出现死亡界面。见[[难度]]。
- 村民和露米归零时倒地 30 秒，然后以一半生命起来。
- 怪物和动物归零就被打倒，打倒它的人得到经验。见[[等级与经验]]。

## 别人的生命条

受了伤的东西头顶会出现一条细细的生命条（对你有敌意的生物不受伤也显示）：

| 颜色 | 是谁 |
|---|---|
| 红 | 会攻击你的 |
| 绿 | 人和露米 |
| 琥珀色 | 其余的：不打算攻击你的生物，被砍过的树、墙等东西（显示的是耐久） |

首领的生命条显示在屏幕顶部。见[[首领]]。

## 提示

- 想回血，先把饱食度吃到九成以上，再找个安全的地方等一会儿。
- 卧室里睡一觉能一次回满。盖一间有床、有门、有天花板的屋子，见[[房间]]。
- 初原村的疗伤温泉不花任何东西，受伤了就回去泡一泡。

- 2026-10-20：左键改为“挥”，只管工具和武器；拿着别的东西做的事改用右键或 {{键|R}}（见[[操作#左键：挥|左键：挥]]）。
