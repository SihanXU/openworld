本页介绍游戏画面上的界面元素。界面仿照几款游戏的做法：时钟和右下角按钮学星露谷物语，心、鸡腿、经验条和物品提示框学 Minecraft。界面文字随[[选项]]里的语言切换。

## 布局

| 位置 | 内容 |
|---|---|
| 左上 | [[世界地图#小地图|小地图]]，下方写着区域 |
| 右上 | 时钟：日期、表盘、天气、时间；下面是任务追踪栏 |
| 上方正中 | 首领血条（靠近首领时）；进入地图时淡入的地名 |
| 正中 | 世界正在学习时的提示 |
| 左下 | 技能栏（贴着屏幕底边），上面是消息 |
| 下方正中 | 心、鸡腿、经验条、快捷栏、副手 |
| 右下 | 八个按钮 |
| 正中偏上，人物头顶 | 动作提示 |

人物走到屏幕下边缘附近时，快捷栏一组会挪到屏幕上方。

## 时钟

右上角的木框。第一行是日期（“第 N 天”）；中间是表盘，指针从 06:00（左）扫到 02:00（右），旁边是天气图标（☀ ☾ ☁ ☂ ⚡ ≋），鼠标停在图标上显示天气名；最下面是时间，每 10 游戏分钟跳一次。见[[游戏内时间]]、[[天气]]。

晴天时，从入夜前 2 个游戏小时到天亮后 1 个游戏小时，天气图标是月亮 ☾，其余时候是太阳 ☀。一开始是 19:00–06:00；故事推进、夜晚变长后，月亮跟着提前出来（见[[昼夜]]）。

## 心、鸡腿和经验条

快捷栏上方，左边十颗心是[[生命值]]，右边十个鸡腿是[[饱食度]]。饱食度为 0 时鸡腿会闪动。下面一条细长的经验条，写着当前等级。鼠标停在上面会显示具体数字。见[[等级与经验]]。

## 快捷栏与副手

十个格子，左上角标着 1–0，选中的那格有框。格子里显示物品图标和数量。右边单独一格是副手，空着时是灰色盾牌轮廓，装着别的职业的盾牌时变灰。点格子可以选中。见[[背包]]、[[装备]]。

## 技能栏

屏幕最左下角一排六个方形的技能格，深色底、带斜面的边框，每格角上标着 ⇧1–⇧6。还没学会主动技能时不显示，学会第一个后出现。放着主动技能的格子显示技能图标；空格是暗的。

- 按 {{键|Shift}}+{{键|1}}–{{键|6}} 或点格子，施放那一格的技能。
- 技能冷却时，一圈暗色像钟面一样扫过格子，中间写着剩余的秒数（不到 10 秒时带一位小数）；冷却好了，格子闪一下。
- 装备借来的技能，脱下装备后还留在格子里，但变灰、放不出来。
- 鼠标停在格子上，显示技能名、冷却秒数、说明和“右键移出技能栏”；停在空格上，提示怎样放技能进来。
- 拖动格子换位置，右键清空。完整的管理在技能面板（{{键|U}}）里。

见[[技能#主动技能与技能栏|主动技能与技能栏]]。

## 面板页签

背包、制作、技能树、技能面板、任务、图鉴、世界地图打开时，屏幕顶部正中有一排页签，当前打开的那个高亮，每个页签上写着它的键。点一个页签就关掉现在的面板、打开那一个。没有职业模块的游戏里不显示技能树和技能面板两页。

## 小地图与区域

左上角，画着当前地图和地图上的人、动物、怪物、传送雕像。下方一条写着“和平区域”（绿底）或“战斗区域 · 夜间有怪物”（红底）。点小地图打开世界地图。见[[世界地图#小地图|小地图]]、[[和平区域与战斗区域]]。

## 任务追踪栏与标记

时钟下面一块半透明的小框是**任务追踪栏**：第一行是追踪中的[[任务]]名（黄字），下面是它没做完的目标，最多四个，带着进度（如「木头 2/4」）；目标在别的地图上时后面写着「→ 地图名」。追踪哪个任务在任务日志（{{键|L}}）里选；没选时是最近开始的主线任务。

追踪中的任务里没做完的目标指向的人或地方，画在这些地方：

- 小地图上一个黄色的菱形；
- [[世界地图]]上一颗黄色的 ★；
- 在当前地图上、但不在屏幕里的，屏幕边缘一个箭头指着它的方向；进了屏幕，变成浮在它上方的菱形。

追踪栏和标记都可以在[[选项]]里关掉。想知道该做什么，也可以对[[露米]]按 {{键|E}}：她会说「现在要：……」，后面是目标、进度和做法。见[[任务#追踪与标记|追踪与标记]]。

## 消息

屏幕左下角的一条条小纸条，最多同时 6 条，5 秒后淡去。

| 边框颜色 | 内容 |
|---|---|
| 绿 | 好消息：捡到东西（“+1 浆果”，连续捡同一种会累加）、升级、接受和完成任务、织入新线 |
| 橙 | 和[[世界会学|世界学习]]有关的：“✦ 世界停顿了一下……”“✦ 世界正在创造新物体：……” |
| 红 | 警告；任务失败 |
| 无 | 普通的叙述：“你吃掉了面包。”“树倒了！”等 |

捡起东西时，物品图标还会从原地画一道弧线飞进人物身上。

## 地名

走进一张地图时，地图名在屏幕上方正中淡入，停留片刻后淡出。

## 动作提示

鼠标指着（或面前）的格子用四个小角框出来，框会滑到下一格。光标显示 {{键|E}} 会做什么：能拿起、打开、阅读的东西上是一只手，人身上是一个对话气泡；那里 {{键|E}} 没事可做、而手上的墙、床这类东西能用右键建在那里时，也是一只手。右键的用法世界从没见过时带一个「?」，{{键|E}} 会拿走别人的东西（偷）时带一个红色「!」。框的上方有一个小提示框，一行一个输入（用鼠标时是左键、右键，再加上 {{键|E}}、{{键|G}}），写着按下去会发生什么；人物停下、框停稳一小会儿才出现，走路时不显示，所以不会跟着脚步乱跳。世界还没定义过的动作，这一项颜色变淡，后面跟一个橙色的「?」。对话、提问、剧情演出时不显示。见[[操作#动作提示与「?」|动作提示与「?」]]。

长按 {{键|E}}、{{键|G}} 或 Alt+点击弹出的“对哪一个？”列表也显示在那个格子下方，每行一个编号。见[[操作#选择叠着的东西|长按：选择对象]]。

## 提示框

鼠标停在快捷栏、背包、箱子或制作面板里的一件物品上，会出现一个深色的提示框，跟着鼠标走：

| 行 | 内容 |
|---|---|
| 名字 | 颜色按[[品质]]：粗制灰、普通白、精良黄、大师青、遗誓紫、圣痕橙红 |
| 品质说明 | 遗誓、圣痕两档各有一句来历 |
| 种类 | 武器、工具、食物、药水、材料、种子、护甲、衣物、照明、容器、贵重品、读物 |
| 拿在手上时 | 攻击伤害（已加上你自己的攻击）、攻击距离、元素、暴击率、攻击速度、每次命中吸取的生命 |
| 装备在副手时 | 防御、格挡率 |
| 穿戴在某处时 | 防御、攻击、经验加成；负数（代价）写成红色 |
| 特性 | 紫色：闪避、移速、入夜加成等 |
| 誓言 | 紫色：遗誓装备的“✦ 誓言名 · 誓言”和一句效果说明 |
| 圣痕之力 | “✦ 力量名 · 唯一”和它的说明 |
| 职业 | “X专属”（自己的职业为橙色，否则红色），或“通用武器：不受职业天赋加成” |
| 食物 | 一排小鸡腿和“+N 饱食度”；能回血的写“+N 生命” |
| 用途 | 蓝色：砍树、劈木头；凿开岩石；耕地；收割作物；能点燃东西；可以用火烤熟；可以种下；着火就会炸开等 |
| 材质与性质 | 紫色斜体：材料名，以及易燃、易碎、沉重、锋利、导电、生的、熟的等 |
| 状态 | 红色：这件东西身上的状态，比如潮湿、燃烧 |
| 主人 | 红色：“属于X” |

## 头顶的东西

- **说话的气泡**：离你较远的人说话时，话显示在他头顶的气泡里，过几秒消失。
- **心情符号**：♥ 高兴、… 难过、!! 生气、! 吃惊、♡ 害羞。
- **任务标记**：黄色的“！”（有任务托付给你）和“？”（现在和他说话能让你的任务往前走：交付，或者任务让你来找他），上下浮动。见[[任务#头顶的标记|头顶的标记]]。
- **职业导师的标记**：[[职业]]导师（初原村的[[布拉姆]]）头顶有一个上下浮动的剑形图标，好找。他头上有任务标记时，先显示任务标记。
- **生命条**：受了伤的东西和对你有敌意的生物头顶有细细的生命条：红色会攻击你，绿色是人和露米，琥珀色是其余的。见[[生命值#别人的生命条|别人的生命条]]。
- **飘字**：受到伤害时飘出“-N”，颜色按元素；回血时飘出绿色的“+N”。
- **世界学习中**：世界在学习一个动作的结果时，做这个动作的人头顶有一个转动的 ✦ 和三个点，被作用的东西半透明闪烁，头顶有“…”。

任务标记、职业导师的标记和生命条画在世界里所有东西的上面：人站在树或房子后面，这些标记照样看得见。

## 对话框

身边 2 格以内的人说话时，屏幕下方出现对话框：左边是头像，上面是名字，文字一个个打出来，右下角的 ▼ 表示还有下文。按 {{键|E}}、{{键|Esc}} 或点一下：第一下把字显示完，第二下翻页。普通的一句话可以按 {{键|G}} 直接收起。剧情演出里的对话要一句句翻完。见[[操作#对话、提问与剧情|对话、提问与剧情]]。

## 是/否提问

吃东西、喝东西前会问“要吃掉X吗？”这类问题。对话框里出现“是”“否”两个按钮。见[[操作#对话、提问与剧情|对话、提问与剧情]]。

## 剧情卡片与黑场

剧情演出中，画面可能整个黑下去再亮起来（黑场），也可能出现一张全屏的文字卡片，比如第一章结尾的那张。按 {{键|E}} 或点一下继续。

## 世界学习中

你做了一件世界没见过的事、世界正在学习它的结果时，屏幕中间显示：“✦ 世界正在学习这件事…… N 秒（最多 20 秒）· Esc 不等了”。见[[世界会学]]。

## 首领血条

靠近[[首领]] 12 格以内时，屏幕上方正中出现首领血条：

- 顶上一顶小王冠和“首  领”字样，下面是首领的名字；
- 当前阶段“Ⅰ / 降临”或“Ⅱ / 觉醒”，以及生命的具体数字；
- 一条宽血条，受伤时先掉一截亮色、再慢慢落下一截暗色；血条上有一道刻度，标着进入第二阶段的生命线；
- 最下面一行是招式条：首领蓄力时写着招式名和“蓄势 / 离开标记区域”，平时写着“观察起手 · 抓住收招空隙”。

剧情演出时首领血条隐藏。

## 新手教程的覆盖层

[[新手教程]]里，屏幕会压暗，只留要操作的东西亮着；要按的键画在它上方，旁边写着“第几课/共几课”；按了被锁的键，按键图标会抖一下；一课完成时屏幕中间弹出一个绿色的 ✓。

## 货摊面板

在[[誓守之地]]对[[货摊]]按 {{键|E}} 打开，标题是「🏪 货摊」。上方四个标签页（农业、牧业、渔业、出售），右边是身上的[[晨辉币]]数；下面一行一样东西，左边是图标，中间是要给的东西和数量（不够的显示成红色），右边是「购买 ×N」或「出售 → N」按钮，能连做时多一个「全部 ×次数」。离开货摊一格以外，面板上写着“站到货摊旁边才能交易。”。见[[金钱]]。
