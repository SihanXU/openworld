**音乐**跟着游戏里正在发生的事走，不是一张地图一首曲子循环到底。野外的曲子放完一首会静下来一阵，只剩**环境声**：风、雨、流水、篝火、白天的鸟和夜里的蟋蟀。环境声是游戏边玩边合成的，没有录音文件。

## 什么时候放什么

从上往下，先满足的那一条说了算：

| 情况 | 放什么 |
|---|---|
| 标题画面 | 标题自己的曲子，不管背后显示的是哪个地点 |
| 剧情演出 | 这场戏指定的配乐，或者一片寂静，直到这场戏结束 |
| [[首领]]战 | 这位首领自己的战斗曲；[[白骑士·阿尔贝里克]]进入第二阶段时换另一首 |
| [[战斗]] | 有东西冲你过来、或者你动手打了谁，战斗曲马上切进来；打完后还会再响 7 秒，然后淡出，回到原来的曲子 |
| 平时 | 这个地点的曲子，按时辰和[[天气]]选版本 |

战斗、剧情或首领战盖过地点曲子的时候，地点的曲子只是暂停，结束后从停下的地方接着放。

倒下（见[[难度]]）时音乐停下，只有倒下的提示音。

## 地点和时辰

每个地点有自己的氛围。同一个地点在清晨、白天、黄昏、夜里、雨天和暴风雨里，可以各放不同的版本：

| 地点 | 白天 | 黄昏和夜里 | 雨天 |
|---|---|---|---|
| [[云顶台地]] | 空灵、孤独的曲子 | 夜里同野外 | 暴风雨时紧张 |
| 野外（[[草原]]、山脚、路上） | 偶尔一首，中间留白很长 | 黄昏忧伤，夜里几乎只剩环境声 | 下雨换忧伤的曲子，暴风雨换紧张的 |
| [[初原村]] | 村庄曲，留白很短 | 黄昏是篝火边的安静曲子，夜里几乎静音 | 下雨换柔和的版本 |
| [[水车磨坊]] | 田园曲 | 同村庄 | 同村庄 |
| [[芦苇湾]] | 河边的曲子 | 黄昏更忧伤，夜里同野外 | 同野外 |
| [[渡口]] | 失落的曲子 | 同野外 | 同野外 |
| [[森林]]、[[烧炭谷]] | 神秘 | 入夜变成阴暗的森林曲 | 同野外 |
| [[荆棘谷]] | 废墟般的曲子 | 夜里阴暗 | — |
| 室内 | 安静的曲子，留白长 | 夜里更安静 | — |
| 商店 | 轻快 | — | — |
| [[初原村礼拜堂]] | 圣歌般的曲子 | — | — |
| 洞穴、矿洞 | 幽深 | — | — |
| [[古墓]]和它的地下室 | 阴森 | — | — |
| [[世界地图]] | 旅途的曲子 | — | — |

黄昏和夜里的时刻跟着[[昼夜]]变化：圣印每倒下一道，夜就更长，黄昏的曲子也来得更早。

## 剧情里的配乐

几场重要的戏有自己的配乐：圣火被夺走的那一夜，灰衣人出现时换成他的主题；第二天早上教会的信使来时；白骑士倒下之后；第一章（也是第一部的结尾）和屠龙的结局卡片。走进白骑士的荆棘圈时，音乐会先静下来，等他动手才响起战斗曲。

## 环境声

| 声音 | 什么时候有 |
|---|---|
| 风 | 室外总有一点；雪地和高处更大，还带一点细细的风啸；暴风雨里最大 |
| 雨 | 下雨和暴风雨时；在屋里听到的是闷闷的雨打屋顶 |
| 雷 | 暴风雨里闪电之后，过一小会儿雷声滚过来 |
| 流水 | 附近水越多越响 |
| 篝火 | 离点着的火越近，噼啪声越响；屋里的壁炉也算 |
| 鸟 | 白天在室外，早上更多；下雨或在雪地里没有 |
| 蟋蟀、猫头鹰 | 夜里在室外，不冷也不下雨的时候；猫头鹰隔很久才叫一次 |
| 滴水、低鸣 | 在洞穴、古墓这类黑暗的地方 |
| 屋里的安静 | 室内一层很轻的底噪 |

## 短乐句

升级、完成[[任务]]、[[露米]]接住圣印之力的时候各有一段短乐句，音乐会在它响的时候让开一下。

## 音量

[[选项]]和标题画面的“设置”里各有两个滑条：**音乐**和**环境声**，默认都是 80%。“声音”开关会把音乐、环境声和音效一起关掉。设置记在浏览器里。
