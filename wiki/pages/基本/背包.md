**背包**装着玩家身上带的所有东西。它有 30 格，分三行，每行十格。第一行就是屏幕下方的**快捷栏**，对应按键 {{键|1}}–{{键|0}}，选中的那一格就是拿在手上的东西。按 {{键|I}} 或点右下角的背包按钮打开背包面板。

## 格子与堆叠

- 30 格，三行。学会[[技能#采集|采集]]分支的{{技能|大背包}}后多一行，变成 40 格。
- 同样的东西叠在一格里：类型、名字、标签、状态都相同才算同样（比如潮湿的木板和干木板分开放）。
- 一格能叠多少都行，没有上限，也没有重量。
- 背包满了（没有空格）时，新拿到的另一种东西会掉在脚下。已有的种类照样能叠进去。

## 快捷栏

- 屏幕下方十个格子，左上角标着 1–0。按数字键、点格子或滚动鼠标滚轮来选。滚轮只在有东西的格子之间跳。
- 选中的格子里那一堆中的一个拿在手上，左键、右键用的就是它。手上的东西不画在人物身上；剑、弓、法杖用来攻击时，会在出手的那一下画出挥剑、拉弓、举杖的动作。见[[操作]]。
- 按 {{键|Tab}}，背包的下一行整行换上来当快捷栏；{{键|Shift}}+{{键|Tab}} 换上最后一行。选中的列不变。
- 人物走到屏幕下边缘附近时，快捷栏会挪到屏幕上方，免得挡住人物。
- 快捷栏右边单独一格是**副手**，平时显示一个灰色的盾牌轮廓。装上盾牌后显示盾牌；别的职业的盾牌装上了也不起作用，格子变灰。见[[装备]]。

## 背包面板

面板分成两半：左边是**角色面板**，右边是**行囊**。窗口太窄时，角色面板排到行囊上方。面板打开时时间暂停。

### 角色面板

左边像一张人物卡：

- **顶上一行**：左边一个绿色的“等级 N”，右边是[[职业]]名（还没选职业时写“无职业”）。
- **中间**：玩家的二次元立绘（[[外观]]里捏的那张脸）放在一个铜边的框里。立绘左边一列是头、耳环、项链、肩、护甲，右边一列是手、戒指、戒指、腰带、脚；立绘下面并排是主手和副手。每格下面写着部位名。
- **空着的部位**画着这个部位的浮雕轮廓（头盔、耳环、项链、护肩、胸甲、手套、戒指、腰带、剑、靴子、盾牌）；穿上东西后格子变成金色，显示那件东西。别的职业的副手装在副手格里时，格子变灰。
- **下面的数值**两列六项：生命（当前 / 上限）、饱食（当前 / 上限）、攻击、武器威力（主手武器的威力，没有时是“—”）、防御、暴击。攻击、防御、暴击是人物自己的数值加上穿着的装备写着的数值。

穿上、脱下的办法见下表和[[装备#穿上与脱下|装备]]。

### 行囊

右边是三行格子（快捷栏那一行单独隔开）。标题行左边写着“行囊”，右边是身上的钱：一枚{{物品|晨辉币}}的图标、钱数和“晨辉币”几个字（见[[金钱]]）。格子下面是“⇅ 整理”和“⤓ 丢下”两个按钮，以及一行操作说明。

| 操作 | 作用 |
|---|---|
| 点一格 | 拿起这一堆，它跟着鼠标走 |
| 拿着一堆时点另一格 | 放下或交换 |
| 按住一格拖到另一格 | 放下或交换 |
| 按住能穿的东西拖到左边的角色面板上 | 穿上 |
| 按住一格拖到面板外 | 整堆丢在面前 |
| 拿着一堆时点面板外的空白处 | 整堆丢在面前 |
| {{键|Shift}}+点 | 在快捷栏和背包其余几行之间移动这一堆 |
| ⇅ 整理 | 工具类排在前面，其余按种类排好，空格挪到最后 |
| ⤓ 丢下 | 把拿起的那一堆丢在面前（面前放不下就放在脚下） |
| 拿起能穿的东西，点左边角色面板上的部位 | 穿上（穿在它自己的部位上） |
| 点角色面板上穿着的东西 | 脱下 |
| 右键一格 | 打开菜单，见下 |
| 鼠标停在一格上 | 显示这件东西的提示框，见[[界面#提示框|提示框]] |

### 右键菜单

在背包或箱子里右键一件东西，可以对它使用五个输入中的几个，就像它摆在地上一样：

- **用X作用于它**：把手上的东西用在这件东西上（等于左键）。
- **把X放进 / 放到它上**：把手上的东西放进或放到它上面（等于 {{键|G}}）。
- **空手摆弄它**：等于对它按 {{键|E}}。
- **装备 / 装备到副手 / 卸下**：能穿戴的东西才有。
- **丢下**：丢在面前。

这样，把手上的东西用在背包里的另一件东西上，不必先把它放到地上。没有规则定义的组合同样会让[[世界会学|世界学习]]。

## 自动吸取

- 规则掉落的东西（砍树掉的木头、打碎的箱子里的木板等）落在 2 格以内时，会自己飞进背包，屏幕左下角显示“+1 名称”。连续捡到同一种东西时，数字会累加。
- {{技能|长臂}}让吸取范围再大 2 格。
- 静静躺着的东西不会被吸：普通难度下倒下时留下的东西、被打倒的生物散落的东西，都要走过去用 {{键|F}} 捡。
- 人物忙着（比如睡觉、倒地）时不吸取。

## 背包里的东西会怎样

- 穿着的装备在身上，不占背包格子：穿上时那一格空出来，脱下时回到背包。见[[装备]]。
- 普通难度下倒下，背包里的东西打成一个[[遗落的包裹]]留在倒下的地方（穿着的装备、手里拿着的武器和重要物品留在身上）。回去按 {{键|E}} 或 {{键|F}} 一次全部拿回。见[[难度]]。
- 背包里的东西随[[存档]]保存。

## 提示

- 把常用的工具和武器放在快捷栏，材料放在下面几行，需要时按 {{键|Tab}} 换上来。
- 背包快满时，在家里放一只[[箱子与容器|箱子]]。
- 整理按钮会把工具排在最前，按完以后快捷栏的内容可能变了，留意手上拿的是什么。
