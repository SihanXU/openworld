**装备**是穿戴在身上的东西：头盔、护甲、靴子、戒指、耳环、盾牌等。身上有十个部位，另有一个副手。穿上的东西提供防御、攻击、经验加成和别的特性。打开[[背包]]（{{键|I}}），左边的[[背包#角色面板|角色面板]]就是身上的部位。

## 部位

{{装备栏表}}

背包面板左边是一张角色面板：玩家的二次元立绘放在中间，左边一列是头、耳环、项链、肩、护甲，右边一列是手、戒指、戒指、腰带、脚，立绘下面是主手和副手。面板顶上写着等级和职业，下面列着生命、饱食、攻击、武器威力、防御和暴击。见[[背包#角色面板|角色面板]]。

**主手**放武器：武器装在主手上，快捷栏切到别的东西时，按 {{键|Space}} 打怪用的还是主手的武器；空着手按左键也一样；拿着火把、工具时左键是用它们本身（点火、干活），拿着别的东西时左键是对自己用；手里另拿一把武器时，用手里那把。武器的数值只在用它打时算一次。空着的部位画着这个部位的浮雕轮廓（头盔、耳环、剑、盾牌……）。戒指有两个位置。

副手单独显示在屏幕下方快捷栏的右边。

## 穿上与脱下

| 方法 | 说明 |
|---|---|
| 拿在手上，左键（或右键点自己） | 拿着能穿的东西按左键就是对自己用，显示“穿上X”；穿上后它就离开手，回到身上。武器的左键是挥，要装备到主手就右键点自己 |
| 背包里点一下拿起，再点左边角色面板上的部位 | 穿上 |
| 点角色面板上穿着的东西 | 脱下 |
| 背包里右键 | 菜单里有“装备”“装备到主手”或“装备到副手” |

- 一件东西只能穿在它自己的部位上。那个部位已经有东西时，旧的自动脱下。
- 穿着的东西在身上，**不占背包格子**：穿上时那一格空出来，脱下时它回到背包（背包满了就掉在脚边）。脱下只能在角色面板上点它。
- 穿上、脱下时左下角提示“你穿上了X。”“你脱下了X。”

## 给别人穿

拿着能穿的东西右键点一个人，提示是“给X穿上Y”：东西交到对方手里，对方穿上（和人说话是 {{键|E}}）。用 {{键|G}} 交给对方则只是送给他：对方收下放在身上，说一句话，但不会穿上。见[[操作#输入|输入]]。

## 数值

- **防御**：每次受到的伤害减去防御，至少 1 点。各部位的防御相加。
- **攻击**：有些装备（手套、戒指等）加攻击。
- **经验**：耳环类饰品多带经验加成，见[[等级与经验]]。
- **副手**：盾牌提供防御和格挡率，格挡率最高 50%。

一件装备的攻击和防御 = 它的形制本身的数值 × 材料的系数 × [[品质]]的系数 × [[#等级|等级]]的系数，取整，至少 1。同一种头盔，铁的比木的硬，精良的比普通的强，5 级的比 1 级的强。见[[材质]]、[[品质]]。

鼠标停在装备上，提示框会写“穿戴在X时：”和它提供的数值；增加的写成绿色，代价写成红色。

**背包里的属性面板**（人物立绘下方）显示的是你现在的全部属性，和战斗里实际用的是同一套计算：自己的、身上穿戴的（包括每件装备的随机词条）、套装加成、状态、露米携带的力量，以及手上武器自带的。一共 16 项：生命、饱食、攻击、武器威力、防御、暴击率、暴击伤害（基础 150%）、闪避、吸血、冷却缩减、经验获取、幸运、移动速度、攻击速度、善恶、信念（善恶与信念见[[善恶与信念]]）。鼠标停在几项上会有说明。

**格子的框色**：背包、装备栏和快捷栏里，装备放在深色底的格子里，边框颜色表示品质（参照 DNF）：粗制灰、普通白、精良蓝、大师紫、遗誓粉、圣痕橙、专属装备金；圣痕和专属装备的边框上还有一道流光。其他物品仍是普通格子。

**衣物的基础属性**（2026-10-12 起）：帽子防御 +1；兜帽防御 +1、闪避 +1%；斗篷防御 +1；靴子防御 +1、移动速度 +3%；手套防御 +1、暴击率 +2%。防御会按材质和品质缩放。

## 等级

每件穿戴或手持的装备都有一个**等级**，1 到 20，写在提示框里名字下面（「等级 5」）。等级是装备数值的一条轴，品质是另一条：

- **主属性随等级增长**：每高一级，攻击、防御、威力的系数 +0.25（1 级 ×1，5 级 ×2，10 级 ×3.25，20 级 ×5.75）；百分比属性（暴击率、闪避、经验、移速等）每级 +0.125。
- **品质乘在等级之上**：同一等级下，品质越高主属性越高（粗制 ×0.8、普通 ×1、精良 ×1.25、大师 ×1.5、遗誓 ×1.75、圣痕 ×2），掷出的[[#词条|小词条]]也越多。所以同等级下品级高的一定更好，同品质下等级高的一定更好。
- **词条随等级变宽**：词条的取值范围每高一级放大 10%（20 级时接近 3 倍）。
- **等级不限制穿戴**：任何等级的装备都能穿，等级只决定它有多强。

一件铁剑：1 级普通威力 6，5 级精良 15，10 级大师 29，20 级（环钢、大师）86。

装备的等级来自它从哪里来：

| 来源 | 等级 |
|---|---|
| [[锻造|锻造]]、[[制作]] | 制作者的等级（不低于配方等级，最高 20） |
| 商人进货 | 商人自己的进货等级：村里的商人 1 级，[[芬尼克]] 2 级，[[奥林]]、[[希尔德]] 2 级，[[加里克]] 4 级 |
| 地图上放着的 | 地图的等级：渡口、初原村一带 1 级，荆棘谷、古墓、烧炭谷、芦苇湾、晨光丘 2 级，荆棘骸骨堂、朝圣者之路 3 级，守墓者圣所、修道院、跪石原、东大路、余烬镇 4 级，骑士团地下墓室、旧矿坑 5 级，烬岭山道 6 级，魔龙巢穴 8 级（有名字的装备可以另写） |
| [[#怪物专属装备|怪物专属装备]] | 那种怪物的等级（史莱姆 1、狼 2、野猪 3、幽灵 4、霜狼 5、魔像 6、独眼巨人 7、魔龙 10，见下表） |
| 任务奖励 | 任务写定的等级：村里的跑腿 1–2 级，朝圣相关 3 级，骑士王国里的 4 级 |
| [[圣痕]]装备 | 10 级，持印者的 |

旧存档里没有等级的装备一律记为 1 级，数值不变。

## 词条
{{主条目|词条}}

每件装备都有两部分数值：

- **主属性**：来自形制本身，再乘以材料、[[品质]]和[[#等级|等级]]的系数；怪物专属装备的主属性由它的等级算出，固定不变。
- **小词条**：随机的几条，在装备“出生”时掷出：锻造出来、商人进货、地图上放着、怪物掉落都算。几条由品质决定：粗制 2 条，普通 3 条，精良 4 条，大师 5 条，遗誓 5 条，圣痕 6 条；怪物专属装备 4 条。各条互不相同，每条在自己的范围里按档位取值，范围随等级放大。

| 词条 | 范围（1 级） | 说明 |
|---|---|---|
| 攻击 | +1～3 | 较少见 |
| 防御 | +1～3 | |
| 暴击率 | +1%～5% | |
| 暴击伤害 | +5%～20% | |
| 闪避 | +1%～4% | |
| 每次命中吸血 | +1 | 稀有 |
| 冷却缩减 | +2%～6% | |
| 经验获取 | +3%～10% | |
| 幸运 | +3%～10% | 怪物掉落几率提高（见[[善恶与信念#幸运|幸运]]） |
| 移动速度 | +2%～6% | 只出现在脚、腰、肩、身体、耳 |
| 攻击速度 | +2%～6% | 只出现在主手、手、戒指、耳、副手 |

穿在身上时，词条和主属性一样加到人身上；武器的词条在用它打的时候也算（拿在手上或装在主手）。提示框里“词条：”一节用蓝色写出。详见[[词条]]。职业的初始武器不带词条；任务里有名字的装备沿用作者给的数值。

## 怪物专属装备
{{主条目|专属掉落}}

每种怪物都有一件自己的**专属装备**。打倒一只，它就有一定几率直接进打倒它的人的背包：普通怪物 4%，较强的 10%，首领类的必掉；同一种怪物连打 50 只都没掉，第 50 只一定掉。专属装备只能打怪得到，主属性由它的等级算出（见[[专属掉落]]），另外照样掷 4 条词条。提示框里写着「✧ 专属装备 · X掉落」。

## 套装
{{主条目|套装}}

同一套的装备穿在一起有额外加成。**防具套装**（头、肩、身体、手、腰带、脚）穿够 2、4、6 件，**首饰套装**（项链、耳环、戒指）穿够 2、3 件，各多一档。件数按部位算，同一套的两只戒指只算 1 件；主手和副手不进套装。每个职业有一身在铁砧上锻造的套装（影刃、誓卫、风行、星辉），同一族怪物的专属装备也组成一套。提示框底部列出这一套的各档加成，已达到的那档是绿色。

怪物专属装备的等级、掉率和主属性见[[专属掉落]]。

## 职业专属

- 有些装备只有某个[[职业]]能用，提示框里写着“X专属”。是你的职业时这一行是橙色，不是时是红色。
- 别的职业的盾牌穿在副手上不起作用，副手格变灰。
- 别的职业的专属武器挥不出去，提示“只有X会用Y战斗。”
- 没有职业限制的武器写着“通用武器：不受职业天赋加成”。

## 遗誓与圣痕

[[品质]]最高的两档只能找到，不能制作：

- **[[遗誓]]**：立誓之人留下的东西。除了更高的数值和 5 条小词条，每件还带一条**誓言**——有条件、有回报的特殊效果，提示框里用紫色写出“✦ 誓言名 · 誓言”和它的说明。十种誓言：

{{誓言表}}

  随机得到的遗誓装备随机带一条；剧情里有名字的那几件各有定好的（奥多的护肩是坚守，玛伦的戒指是怜悯，托马斯的腰带是守夜，扇贝是朝圣，芬尼克的头盔是庇护，卡西安的祈祷绳是黎明，骑士团印章是荆棘）。同一条誓言戴两件不叠加。见[[遗誓]]。
- **[[圣痕]]**：带着初殉者五道伤痕之一的东西，只有[[持印者]]身上有。每件都有一种独一无二的力量，提示框里写着“✦ 力量名 · 唯一”。有的还要付出代价，比如戴上{{物品|荆棘冠}}，经验加成 −50%。见[[圣痕]]、[[传说武器]]。

## 没有的东西

- 每个职业有一套防具套装和一套首饰套装，另有五套怪物套装，见[[套装]]。
- 装备没有耐久度，不会穿坏，也不需要修理。
- 头盔、帽子、头冠、荆棘冠、胸甲、护肩和斗篷穿上后会画在身上，地图小人和对话立绘都一样，颜色取自它的材质（铁头盔是铁灰色，青铜的是青铜色），并给人带上相应的外貌标签（如“披甲”`look:armoured`）。脱下就恢复原样。其余部位（靴子、手套、腰带、首饰）不显示。见[[外观#穿在身上的东西|外观]]。

## 提示

- 早期最容易拿到的装备来自任务奖励，比如完成[[下山]]得到的旅人的靴子、[[古墓里的失踪者]]的罗万的旧锁甲。见[[任务]]。
- 普通难度下倒下时，穿着的装备（包括主手的武器）留在身上；背包里的东西打成[[遗落的包裹]]留在倒下的地方。见[[难度]]。
- 给别人穿上的东西就是对方的了。

## 历史

- 2026-10-13：装备有了等级（1–20）：主属性和词条范围随等级增长，词条条数随品质增加，同等级下品质高的一定更好；锻造的装备取制作者的等级，商人、地图、怪物、任务各有自己的等级；怪物专属装备和任务奖励的主属性改为按等级算出；穿在身上的装备鼠标移上去也能看属性。
- 2026-10-12：背包的属性面板改为显示全部 16 项属性（含词条、套装、状态、露米的力量）；手套、靴子、帽子、兜帽、斗篷有了基础属性。
- 2026-10-12：加入随机词条（每件装备 4 条）、怪物专属装备（每种怪物一件，打 50 只保底）和五套怪物套装；套装参照 DNF 分成防具套装和首饰套装。
- 2026-10-11：背包面板改成角色面板，部位排在立绘两侧，空着的部位画出浮雕轮廓。
- 2026-10-11：加入套装：四套职业套装，同套多件有加成；新的身体形制皮甲、法袍，刺客、游侠、法师有了自己的副手（格挡短刃、箭袋、法典）。
- 2026-10-09：穿着的东西不再占背包格子。

- 2026-10-04：加入穿戴：身上的部位、防御和攻击按形制、材料和品质计算；能穿的东西也能左键给别人穿上。
- 2026-10-05：加入副手和职业专属装备。
- 2026-10-07：加入遗誓和圣痕两档品质，背包旁边加入十个部位的装备栏；任务奖励里加入有名字的装备。
- 2026-10-08：加入主手；普通难度下倒下时，穿着的装备留在身上。
- 2026-10-12：属性面板去掉坚守、潜行、感知，加入幸运、善恶、信念；装备上的这三种属性换成防御、闪避或幸运（旧存档自动换算）。
- 2026-10-13：遗誓装备带誓言（十种特殊效果），并且和别的装备一样掷小词条；旧存档里的遗誓装备自动补上誓言、词条，数值补到遗誓应有的水平。
- 2026-10-21：操作定为四个输入：拿着物件对东西用改成右键（左键是手上东西本身的用法：工具、武器挥，别的东西对自己用），拿起散落的东西改成 {{键|E}}（见[[操作]]）。
