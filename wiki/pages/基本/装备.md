**装备**是穿戴在身上的东西：头盔、护甲、靴子、戒指、耳环、盾牌等。身上有十个部位，另有一个副手。穿上的东西提供防御、攻击、经验加成和别的特性。打开[[背包]]（{{键|I}}），右边的“装备”栏就是身上的部位。

## 部位

{{装备栏表}}

背包面板右边按身体排成一个“纸娃娃”：耳环、头、项链；肩、护甲、手；戒指、腰带、戒指；主手、脚、副手。

**主手**放武器：武器装在主手上，快捷栏切到别的东西（火把、食物、工具）时，按 {{键|Space}} 或空手左键打怪，用的还是主手的武器；手里另拿一把武器时，用手里那把。武器的数值只在用它打时算一次。空着的部位显示一个灰色的轮廓符号。戒指有两个位置。

副手单独显示在屏幕下方快捷栏的右边。

## 穿上与脱下

| 方法 | 说明 |
|---|---|
| 拿在手上，右键 | 右键是对自己用。能穿的东西显示“穿上X”；穿上后它就离开手，回到身上 |
| 背包里点一下拿起，再点右边的部位 | 穿上 |
| 点装备栏里穿着的东西 | 脱下 |
| 背包里右键 | 菜单里有“装备”“装备到主手”或“装备到副手” |

- 一件东西只能穿在它自己的部位上。那个部位已经有东西时，旧的自动脱下。
- 穿着的东西在身上，**不占背包格子**：穿上时那一格空出来，脱下时它回到背包（背包满了就掉在脚边）。脱下只能在装备栏里点它。
- 穿上、脱下时左下角提示“你穿上了X。”“你脱下了X。”

## 给别人穿

拿着能穿的东西左键点一个人，提示是“给X穿上Y”：东西交到对方手里，对方穿上。用 {{键|G}} 交给对方则只是送给他：对方收下放在身上，说一句话，但不会穿上。见[[操作#五个输入|五个输入]]。

## 数值

- **防御**：每次受到的伤害减去防御，至少 1 点。各部位的防御相加。
- **攻击**：有些装备（手套、戒指等）加攻击。
- **经验**：耳环类饰品多带经验加成，见[[等级与经验]]。
- **副手**：盾牌提供防御和格挡率，格挡率最高 50%。

一件装备的攻击和防御 = 它的形制本身的数值 × 材料的系数 × [[品质]]的系数，取整，至少 1。同一种头盔，铁的比木的硬，精良的比普通的强。见[[材质]]、[[品质]]。

鼠标停在装备上，提示框会写“穿戴在X时：”和它提供的数值；增加的写成绿色，代价写成红色。

## 词条

每件装备都有两部分数值：

- **主属性**：固定值。来自形制本身，再乘以材料和[[品质]]的系数；怪物专属装备的主属性是它自己的，固定不变。
- **小词条**：随机的 4 条，在装备“出生”时掷出：锻造出来、商人进货、地图上放着、怪物掉落都算。4 条互不相同，每条在自己的范围里按档位取值。

| 词条 | 范围 | 说明 |
|---|---|---|
| 攻击 | +1～3 | 较少见 |
| 防御 | +1～3 | |
| 暴击率 | +1%～5% | |
| 暴击伤害 | +5%～20% | |
| 闪避 | +1%～4% | |
| 每次命中吸血 | +1 | 稀有 |
| 冷却缩减 | +2%～6% | |
| 经验获取 | +3%～10% | |
| 潜行 | +1～2 | 较少见 |
| 坚守减伤 | +5%～15% | 站定不动时受到的伤害减少 |
| 感知 | +1～2 | 较少见 |
| 移动速度 | +2%～6% | 只出现在脚、腰、肩、身体、耳 |
| 攻击速度 | +2%～6% | 只出现在主手、手、戒指、耳、副手 |

穿在身上时，词条和主属性一样加到人身上；武器的词条在用它打的时候也算（拿在手上或装在主手）。提示框里“词条：”一节用蓝色写出。职业的初始武器不带词条；任务里有名字的装备沿用作者给的数值。

## 怪物专属装备

每种怪物都有一件**专属装备**（一件，不是一套）。打倒一只，它就有一定概率直接出现在打倒它的人的背包里，左下角提示“获得专属装备：X！”。

- **掉率**：普通怪物 4%，较强的怪物 10%，首领一定掉落。
- **保底**：同一种怪物连续打倒 50 只都没掉，第 50 只一定掉。每种怪物各自计数，掉了以后从头算。
- 专属装备只能打怪得到，不能锻造，商人也不卖。主属性固定，另外照样掷 4 条小词条，所以同一件专属装备每次掉的都不一样。
- 提示框里写着“✧ 专属装备 · X掉落”。

## 怪物套装

参照 DNF，套装分两种，[[锻造#套装|职业套装]]也一样：

- **防具套装**（6 件）：头、肩、身体、手、腰带、脚，穿够 2、4、6 件各多一档加成。
- **首饰套装**（3 件）：项链、耳环、戒指，穿够 2、3 件各多一档加成。

同一族怪物的专属装备组成其中一套。件数按部位算：同一件戒指两只手都戴，只算 1 件。武器和副手不进套装。有两个首领的专属装备是**单件**，不属于任何套装，但单件的主属性更高。提示框底部列出这一套的各档加成，已达到的那档是绿色。

## 职业专属

- 有些装备只有某个[[职业]]能用，提示框里写着“X专属”。是你的职业时这一行是橙色，不是时是红色。
- 别的职业的盾牌穿在副手上不起作用，副手格变灰。
- 别的职业的专属武器挥不出去，提示“只有X会用Y战斗。”
- 没有职业限制的武器写着“通用武器：不受职业天赋加成”。

## 遗誓与圣痕

[[品质]]最高的两档只能找到，不能制作：

- **[[遗誓]]**：立誓之人留下的东西。除了更高的数值，还随机带一条誓言的特性：暴击率 +5%、闪避 +6%、每次命中吸取 1 点生命、移动速度 +10%、站定不动时受到的伤害 −15%、入夜后防御 +2、入夜后攻击 +1 之一。提示框里用紫色写出。
- **[[圣痕]]**：带着初殉者五道伤痕之一的东西，只有[[持印者]]身上有。每件都有一种独一无二的力量，提示框里写着“✦ 力量名 · 唯一”。有的还要付出代价，比如戴上{{物品|荆棘冠}}，经验加成 −50%。见[[圣痕]]、[[传说武器]]。

## 没有的东西

- 每个职业有一套防具套装和一套首饰套装，见[[锻造#套装|套装]]；另有五套怪物套装，见上文[[#怪物套装|怪物套装]]。
- 装备没有耐久度，不会穿坏，也不需要修理。
- 头盔、帽子、头冠、荆棘冠、胸甲、护肩和斗篷穿上后会画在身上，地图小人和对话立绘都一样，颜色取自它的材质（铁头盔是铁灰色，青铜的是青铜色），并给人带上相应的外貌标签（如“披甲”`look:armoured`）。脱下就恢复原样。其余部位（靴子、手套、腰带、首饰）不显示。见[[外观#穿在身上的东西|外观]]。

## 提示

- 早期最容易拿到的装备来自任务奖励，比如完成[[下山]]得到的旅人的靴子、[[古墓里的失踪者]]的罗万的旧锁甲。见[[任务]]。
- 普通难度下倒下时，穿着的装备（包括主手的武器）留在身上；背包里的东西打成[[遗落的包裹]]留在倒下的地方。见[[难度]]。
- 给别人穿上的东西就是对方的了。
