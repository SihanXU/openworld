**选项**面板在游戏中按 {{键|Esc}} 打开（什么面板都没开时），也可以点屏幕右下角标着 Esc 的齿轮按钮。面板打开时时间暂停。

## 内容

| 项目 | 作用 |
|---|---|
| 语言 | 在中文和英文之间切换，按钮写着“中文 → English”或“English → 中文”。界面、对话、物品名都会立刻换成另一种语言 |
| 声音 | 开或关。关掉后音乐、环境声和音效都没有声音 |
| 音乐、环境声 | 两个滑条，各自调大小，默认 80%。见[[音乐与环境声]] |
| 任务追踪栏 | 开或关。关掉后右上角时钟下面不再显示追踪中的任务和目标。见[[任务#追踪与标记|追踪与标记]] |
| 任务标记（地图和屏幕边缘） | 开或关。关掉后小地图上的菱形、世界地图上的 ★、屏幕边缘的箭头都不再显示 |
| 保存 | 保存到当前存档位，提示“已保存到存档 N”。见[[存档]] |
| 保存并返回标题 | 先保存，再回到标题页 |
| 模组控制台（开发） | 只在开发版里出现，打开[[模组控制台]] |
| AI | 像画质设置一样给 AI 分档：一行预设，五行各自调「关 / 低 / 中 / 高」，下面是连着的模型和「检测」。见[[世界会学#AI 设置|AI 设置]] |
| 操作 | 面板下半部分是一张按键表（见[[操作#游戏里的按键表|游戏里的按键表]]） |

## 说明

- 第一次打开游戏时语言是英文。标题页的“设置”里也能切换语言、声音、画面滤镜、改键和 AI 设置。
- 语言、声音、任务追踪栏、任务标记和 AI 设置都记在浏览器里，下次打开还在，和存档无关。
- 没有音量滑块：音乐的音量是固定的，只能整体开关。
- 没有画面、分辨率之类的设置。AI 设置是唯一按档位调的一项。
- 按键在按键表旁边的“改键…”里改：除了 {{键|Esc}} 和 {{键|`}}，每个按键都能改；鼠标左右键不能改，也没有成套的预设方案（见[[操作#改键|改键]]）。
- 难度在开新游戏时选定，之后不能在选项里改。见[[难度]]。

## 按键表

表格按你现在的键位生成（标题旁边的“改键…”打开按键页，见[[操作#改键|改键]]）。默认键位下，表里一行一个按键：移动、{{键|B}} 建造（左键或 {{键|E}} 放置，{{键|R}} 旋转，{{键|Esc}} 或右键退出）、左键是手上东西本身的用法（武器打、工具干活，工具敲床、工作台、墙这类东西会让它整个掉下来；空手用主手武器或拳头；拿着别的东西就是对自己用：吃、喝、穿戴）、右键把手上的东西用在指着的东西上（播种、开锁、烤肉、喂牲口，以及世界没见过的任何试验；拿着墙、地板、床这类东西就建在那里，拿着地板时按 {{键|R}} 改为铺天花板；空手什么都不做）、{{键|E}} 手（拿起散落的东西；说话、打开、阅读、睡觉、摘成熟的作物）、{{键|G}} 放（把手上的东西放下、放进去、交给别人；放下的床这类东西是散落的，不会建起来）、{{键|空格}} 攻击、{{键|Q}} 冲刺、{{键|X}} 拔出或收起武器、{{键|V}} 潜行（潜行时对人按 {{键|E}} 是扒窃）、{{键|Shift}}+{{键|1}}–{{键|6}} 施放技能栏那一格的技能（在技能树上：把技能放进那一格）、长按 {{键|E}} · {{键|G}} 或 Alt+点击选择叠着的东西（包括天花板）、{{键|1}}–{{键|0}} 和滚轮选手上的东西、{{键|Shift}}+{{键|Tab}} 换快捷栏的一行、{{键|Tab}} · {{键|I}} 背包，然后是面板键：{{键|Esc}} 菜单、{{键|C}} 制作、{{键|K}} 技能树、{{键|U}} 技能面板、{{键|M}} 地图、{{键|L}} 任务、{{键|J}} 图鉴（含[[织线簿]]），最后一行写着在“选项 → 按键”里能改任何一个键（鼠标左右键不能改）。开发版里多一行 {{键|`}} 模组控制台。每个键的详细说明见[[操作]]。
