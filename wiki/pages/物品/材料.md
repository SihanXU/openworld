**材料**是制作、建造和交任务用的物品。最常用的五种是[[树枝]]、[[石块]]、[[干草]]、[[木头]]和[[木板]]：第一把斧头、营火、墙、床都从它们开始。

材料是物品的一个分类；物品是用什么做的（木、石、铁……）叫「材质」，见[[材质]]。

## 常用材料

| 材料 | 从哪里来 | 用在哪里 |
|---|---|---|
| [[树枝]] | 地上会不断长出来；砍倒一棵树掉 1 根 | 石制工具、火把、营火、栅栏、路牌、木盾牌、木弓 |
| [[野花]] | 对地上的野花丛按 {{键|E}} 采下 | 送礼、{{物品|花束}}、魔法工作台的治疗药水、[[奥黛特]]改样子的工钱 |
| [[石块]] | 地上会不断长出来；用镐凿岩石（1 块）或巨石（4 块） | 石制工具、营火、[[领地扩建]] |
| [[干草]] | 地上会不断长出来（割下的草） | 石制工具、火把、床、木桶、木弓 |
| [[木头]] | 用斧砍倒一棵树掉 2 根（学了伐木工多 1 根） | 劈成木板；棍棒；格斯的任务[[给火堆添柴]]；[[领地扩建]] |
| [[木板]] | 斧头点地上的木头，或者带着斧在制作面板里做：1 根木头出 2 块 | 墙、地板、门、楼梯、床、工作台、木桶、盾牌、箱子；修晚祷渡的桥 |
| [[铁矿石]] | 用镐凿[[烬脉旧矿]]的铁矿脉（每条 2 块）；[[独眼巨人]]和持印者倒下时掉落 | 加里克锻屠龙剑；[[领地扩建]]的土地 II；在点着的熔炉里炼成铁锭 |
| [[铁锭]] | 拿铁矿石右键点点着的[[熔炉]]，一块炼一块；或对熔炉按 E 打开面板按[[锻造]]配方成批炼 | 在铁砧上打成武器、护甲、工具、首饰；卖给商人 |
| [[金锭]] | 拿金矿石右键点点着的熔炉，一块炼一块；学会金匠后也能按配方炼 | 打成戒指和护符；卖给商人（价值 75） |
| [[钢条]] | 学会炼钢术后，在熔炉面板里用 3 铁矿石、3 煤炭炼 2 根 | 在铁砧上打成钢的武器、护甲和工具；卖给商人 |
| [[煤炭]] | 用镐凿烬脉旧矿的煤层（每条 2 块）；烧焦的树和烧焦的木墙被打坏时留下 | 加里克锻屠龙剑 |
| [[草药]] | [[晨光丘]]上的晨光花，会慢慢长回来；自己种（种子在[[货摊]]买） | 吃（回一点生命）；伊尔丝的任务[[守夜之备]]；卖给货摊 |
| [[火焰草]] | [[初原村]]的草地上，会慢慢长回来 | 雷恩熬防火药剂 |
| [[霜盖菇]] | [[噤声林]]里，会慢慢长回来 | 雷恩熬防火药剂 |
| [[骨头]] | [[晚祷渡]]的地上有两根 | — |
| [[灰烬]] | 能烧的东西烧完后留下 | 当肥料：施过肥的作物用镰刀收割时多收 1 份 |
| [[肥料]] | [[誓守之地]]的[[货摊]]买 | 和灰烬一样施肥 |
| [[麦子]] | 自己种（麦种在货摊买） | 喂动物；卖给货摊 |
| [[饲料]] | 货摊买 | 喂动物：吃饱的牛能挤奶，两只吃饱的同类会生幼崽 |

地上的树枝、石块和干草每隔一段时间（{{数值|地面产出间隔}} 秒）长出一份，直到一张地图上有一定数量为止。

## 打坏东西得到材料

东西被打坏时，会留下构成它的材料的一半（{{数值|回收比例}}）：一棵树是 4 根木头和 2 根树枝，砍倒后留下 2 根木头和 1 根树枝；一面木墙是 2 块木板，打坏后留下 1 块。自己做的东西被打坏，也只能拿回一半原料；用斧头、镐或锤子把墙、地板这类建筑件敲松，则是整件拿回。见[[耐久与破坏]]。

## 没有来源的材料

[[布匹]]、[[皮革]]、[[羊毛]]、[[蜂蜡]]、[[盐]]等形制目前地图上没有固定来源。

- [[金矿石]]在[[烬脉旧矿]]深处的金矿脉里挖；[[领地扩建]]第三级要 3 块；也能在熔炉里炼成金锭。
- [[麦子]]要自己种：麦种在[[誓守之地]]的[[货摊]]买。
- [[羽毛]]只有[[小鸡]]被打倒时有一半几率留下一根。
- [[肥料]]和[[饲料]]在货摊买，见[[农耕#施肥|施肥]]和[[动物#喂食|喂食]]。
