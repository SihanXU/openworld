游戏里有六种元素：火、水、冰、雷、风、土。元素碰到东西会起反应：火点着干草，水浇灭火，冰冻住湿了的史莱姆，雷顺着湿地传开。这些反应都是规则，对玩家、居民、怪物、物品、地面一视同仁。

## 六种元素

{{元素表}}

武器、法杖带着元素时，名字前面有元素的名号：炽焰（火）、潮汐（水）、寒霜（冰）、雷霆（雷）、疾风（风）、岩土（土）。

## 元素从哪来

- **武器**：带元素的武器、法杖、魔杖，打中谁，元素就落到谁身上（打击本身的伤害照算）。
- **生物**：有些怪物自带元素，它们的攻击带着自己的元素：{{怪物|火焰史莱姆}}、{{怪物|火焰小鬼}}、{{怪物|幼龙}}、{{怪物|烬峰魔龙}}（火），{{怪物|冰霜史莱姆}}、{{怪物|霜狼}}、{{怪物|幽灵}}（冰），{{怪物|石魔像}}（土）等。
- **火把、火镰、蜡烛**：拿着左键点东西，就是用火去碰它。
- **水**：装满水的木桶、瓶子、水袋，左键点东西就是泼水。
- **天气**：下雨是不带力道的水，淋在露天的人、生物和烧着的东西上；雷暴天每隔一阵落一道雷（见[[天气]]）。
- **地面**：踩进泥潭会被弄湿；烧着的东西会点着碰到它的东西；带电的地面会电到站在上面的人。

## 火

| 碰到 | 结果 |
|---|---|
| 沾了油的东西 | 爆炸：自己烧起来，周围 1 格内能烧的东西有 70% 几率也烧起来。 |
| 湿的东西 | 烘干（冒蒸汽），不着火。湿的生物还会受伤（力道 × 0.8）。 |
| 冻住的东西 | 化开，变湿。冻住的生物还会受伤（力道 × 0.5）。 |
| 能点的东西（营火、火盆、路灯、烛台、灯笼柱、熔炉、坩埚） | 没点着的点着（{{状态|点燃}}）；已经点着的没变化，木头的灯笼柱也不会因此烧起来。 |
| 能烧的东西（木头、干草、树、木墙、皮毛、布……） | 烧起来（{{状态|燃烧}}）。 |
| 会炸的东西（{{物品|爆竹}}、{{物品|黑火药炸弹}}） | 一烧起来就炸开：上下左右紧挨着的四格里的一切挨一记火属性的打击（爆竹力道 1，炸弹 8），那几格里能烧的东西被点着，它自己没了。 |
| 火属性的生物 | 回复 2 点生命。 |
| 别的生物和人（不湿、没冻住、没在烧） | 烧起来，2.5 秒。 |
| 生的食物 | 烤熟（见[[烹饪]]）。 |
| 冰面 | 化成水。 |
| 别的东西 | 没变化。 |

**取暖**：空手对点着的火（营火、火盆、熔炉……）按 {{键|E}}，火以 0 的力道碰到你：湿的被烘干，冻住的会化开，都不受伤（受伤按力道算）。冻住时不能行动，所以实际用得上的是烘干。见[[营火#取暖|取暖]]。

**烧起来以后**：
- 烧着的东西每半秒有一半几率掉 1 点耐久（见[[耐久与破坏]]）。
- 每半秒，它有几率把火传给旁边能烧的东西：地面 7%，干的地面（枯草）30%，家具 10%，干的家具 30%，墙、地板、楼梯、门这些建筑件 10%。湿的、冻住的不会被传上。
- 被风吹到时，火向周围 2 格乱窜（50% 几率）。
- 烧完：地面变成灰烬，树变成焦木，木墙变成焦黑的木墙，家具变成一份 {{物品|灰烬}}（里面的东西掉出来），物品变成灰烬。
- 建筑件（{{物品|墙}}、{{物品|地板}}、{{物品|楼梯}}、{{物品|门}}）火灭了还在，只少了耐久；烧着时耐久掉光，才变成一份灰烬。
- 水上不会着火。

## 水

| 碰到 | 结果 |
|---|---|
| 烧着的东西 | 浇灭，变湿（{{状态|潮湿}}）。 |
| 点着的东西（营火、灯） | 熄灭。 |
| 水本身 | 没变化。 |
| 火属性的生物 | 受伤（力道 × 1.2）并变湿；下雨只让它们变湿冒烟。 |
| 还在长的作物 | 浇了水（见[[农耕]]）。 |
| 别的东西 | 变湿。 |

湿了的东西 40 秒后才干。湿的东西不会被火点着，却会被冰冻住、被雷电到。

## 冰

| 碰到 | 结果 |
|---|---|
| 烧着的东西 | 灭火。 |
| 湿的东西 | 冻住（{{状态|冰冻}}，4 秒不能动），同时开始 8 秒的 {{状态|刚解冻}}：这 8 秒内不会再被冻住。 |
| 浅水 | 冻成薄冰，人能走上去；周围 1 格的水有 70% 几率也冻上。薄冰 150 秒后化回水，站在上面的人被送上岸。 |
| 冰属性的生物 | 回复 2 点生命。 |
| 别的东西 | 没变化。 |

**冻住的身体怕钝器和土**：被钝器或带土元素的攻击打中，伤害 × 1.5，冰也碎了。

## 雷

| 碰到 | 结果 |
|---|---|
| 湿的东西 | 不再湿，变成 {{状态|感电}}（0.8 秒不能动）；雷顺着周围 2 格内湿的东西传过去（90% 几率）。湿的生物还会受伤（力道 × 0.8）。 |
| 导电的东西（金属、水） | 感电。水面感电后，把雷传给周围 2 格内导电的和湿的东西。 |
| 干的、能烧的东西（枯草、干草垛） | 烧起来。 |
| 雷属性的生物 | 没变化。 |
| 魔像 | 受伤（力道 × 0.5），不会感电。 |
| 别的生物 | 感电。 |

雷暴天落下的雷有一半的时候劈向玩家周围 12 格内高的东西（比如枯树）。

## 风

| 碰到 | 结果 |
|---|---|
| 烧着的东西 | 火向周围 2 格乱窜，50% 几率点着能烧的东西。 |
| 生物和人 | 被吹开 2 格，方向背离风吹来的地方。 |
| 别的东西 | 没变化。 |

风是游戏里少数会把人推开的东西（另一种是首领的技能）。

## 土

| 碰到 | 结果 |
|---|---|
| 易碎的家具（陶罐这类） | 碎掉，里面的东西掉出来。 |
| 冻住的生物 | 打击伤害 × 1.5，冰碎了。 |
| 别的东西 | 没变化。 |

## 油

油不是元素，但和火有关：拿着一瓶灯油左键点一样东西，油就泼在它上面，它 {{状态|油污}} 90 秒。沾了油的东西碰到火就会爆炸，见上文。游戏里的灯油不多：[[托宾]]货车上有一瓶（是托宾的），[[磨坊地窖]]里有任务要用的守夜灯油。

## 抗性

每种元素都有对应的抗性，按百分比减少这种元素造成的伤害：100% 完全不受伤，负数反而伤得更重。喝下 {{物品|防火药剂}}，300 秒（5 游戏小时）内火抗 75%，也不会烧起来（{{状态|防火}}）。元素反应里的伤害也算那种元素的伤害。

## 提示

- 先泼水再放雷：湿了的一群敌人会一起感电，电还会传开。
- 冰冻住的敌人，用钝器打伤害多一半。
- 火在枯草上蔓延得很快。下雨天放火基本烧不起来。
- 别在自己的木房子里玩火：墙、地板、床都是木头的，都会烧。

## 历史

- 2026-09-30：游戏第一版就有元素反应：火点燃、水浇灭、冰冻住湿的东西、雷电湿的东西、油遇火爆炸。
- 2026-10-02：冰把水冻成薄冰，薄冰过一阵化回水。
- 2026-10-04：元素有了对应的抗性；防火药剂改成给 75% 火抗的状态（W8）。
- 2026-10-07：冻住一次后有一阵「刚解冻」，不会被连续冻住。
- 2026-10-08：爆竹、黑火药炸弹着火会炸开；烧着的建筑件会把火传开，烧光变成灰烬；点着的灯笼柱再碰到火不会烧起来。
- 2026-10-09：在点着的火旁取暖：火以 0 的力道碰到人，烘干潮湿，不伤人。
