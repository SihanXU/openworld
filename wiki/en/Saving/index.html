Saving

From the OpenWorld Wiki · Gameplay
The Chinese page has changed since this translation was made: some of this may be out of date.

OpenWorld keeps its saves in the browser, in three save slots. The game saves automatically, and you can also save by hand in the Options. A save can be exported as a file on your computer and imported again in another browser or on another computer. The threads the world has learned belong to no single save: all saves share them.

Save slots

  • There are three save slots: Slot 1, Slot 2 and Slot 3.
  • Each slot's card shows: location · day and time · level · current objective (the first unfinished objective of the quest you are tracking, or the quest's name when there is none), for example “Cloudtop · Day 1 13:00 · Lv 1 · The shrine stone at the mountain's foot”, with the date and time it was saved below. An empty slot reads “Empty”.
  • On Hardcore difficulty, a save that has ended reads “Hardcore · ended · location · day N” and can no longer be loaded. See Difficulty.
  • “Continue” on the title page loads the most recently saved slot (skipping any that have ended).

Starting a new game means choosing a slot. When the slot already holds progress, the button reads “Overwrite & start”, and the game first asks “Slot N already has progress. Overwrite it?”.

Autosave

The game saves to the current slot automatically, without a message, at these times:

When Notes
About once every real minute Postponed while you are in danger, and made once you are safe
After you walk onto a new map Likewise waits until you are safe
Whenever any quest reaches a new stage Likewise waits until you are safe
When you switch to another browser tab or minimize the window
After starting or loading a save A new game takes the slot at once

“In danger” means: you were hurt within the last 15 seconds, or something hostile to you is within 8 cells. That way loading a save never drops you back into a fight you are losing.

The game does not autosave while the player is down, so a load always takes you back to before you fell. Hardcore is the exception: the moment you fall, the “ended” state is saved.

Saving by hand

  • Press Esc to open the Options and click “Save”; the message “Saved to slot N” appears.
  • Click “Save & back to title” to save and then return to the title page. From the title page you can switch slots or start a new game.

Export and import

In the “Load game” panel on the title page:

  • Export: saves this slot as a .json file on your computer, with a name like openworld-slot1-day3-2026-10-08.json.
  • Import: pick a save file from your computer and load it into this slot. If the slot already holds progress, you are asked to confirm first. If the file you pick is not an OpenWorld save, the message reads “That file is not an OpenWorld save.”
  • Delete: asks first, “Delete slot N? This cannot be undone (unless you exported it).”

The note at the bottom of the panel: saves are kept in this browser; exporting stores one as a file, or carries it to another browser. Clearing the browser's data clears the saves with it.

What a save holds

Travels with the save Does not travel with the save
The state of the whole world: every map you have visited, every thing, where every person is The threads the world has learned (the shared rule library, common to every save and every player)
The player's inventory, equipment, level, skills and quest progress Language and sound settings (kept in the browser)
The time, the weather, the story's progress, the difficulty
What you have seen in the Codex

A new game does not erase the threads the world has learned. See The World Learns.

Versions

  • After the game updates, an older save from the same version of the world is upgraded to the present form as it loads (for example, the bird in an old save becomes the fairy Lumi).
  • A save from a different version of the world cannot be continued. Loading it starts a new game in that slot, with the message “That save is from another version of the world: a new game began in its slot.” The old progress is overwritten, so export an important save first.
  • Earlier versions had only one save; it is moved into Slot 1 automatically when you open the game.
  • A save card without a summary reads “A save from an earlier version”.

Modes that do not save

  • The Tutorial writes to no save slot. Clicking “Save” in the tutorial only shows “The tutorial keeps no save.”
  • The Boss Challenge is separate from saves.

Tips

  • To keep your progress at a particular moment, export a file; this is also a way to back up when three slots are not enough.
  • When you change computers or browsers, export in the old browser first, then import in the new one.
  • When a private (incognito) window is closed, the browser clears the saves made in it.

History

  • 2026-10-03: Added three save slots, the save panel on the title page, and export and import. The old single save moves into Slot 1 automatically.
  • 2026-10-04: Added difficulty; on Hardcore the save ends when you fall.
  • 2026-10-06: Autosaves happen only when you are safe, and never while you are down; autosaves and saves on switching tabs no longer show a message.
  • 2026-10-06: The tutorial became a separate mode that does not save.
  • 2026-10-09: The objective on save cards is now the tracked quest's objective; any quest reaching a new stage triggers an autosave.
