This page explains how a page file is written, for the English edition. If you have not read [[Editing Basics]] yet, read that page first: its last section explains how an English page follows its Chinese one.

## Where files go

Every English page is a Markdown file under `wiki/en/pages/`, at **the same path, with the same Chinese file name,** as the Chinese page it translates: `wiki/pages/人物/伊尔丝修女.md` is translated by `wiki/en/pages/人物/伊尔丝修女.md`. The two are paired by their path, not by their titles, so an English file is never renamed or moved on its own. The subfolders only sort the files and do not affect the address.

The address depends only on the English title: `/wiki/en/Sister_Ilse`, with spaces written as `_`. The English title is the `title:` in the front matter, or, for a page about a game thing, the game's English name.

Titles are unique across the edition; if two pages end up with the same title, the build reports an error.

## Front matter

The very top of the file is a few lines of "key: value", between two `---` lines:

```
---
summary: The keeper of the fire in Firstlight Village's chapel.
categories: Firstlight Village
aliases: Ilse
source: 3f9a1c0b7d2e
---
```

| Key | Required | Description |
|---|---|---|
| title | For a page not about a game thing | The page's English title. A page about a game thing (a person, an item, a monster, a location, a quest…) takes the game's English name as its title, and a `title:` there is ignored. |
| summary | Recommended | One sentence, used in search results and lists. |
| categories | No | Comma-separated, in English. The page's type already adds its default category (a person goes into "Residents", a location into "Locations"…); write only the extra ones, as the Chinese page's 分类. Each category has its page, `Category:Firstlight Village`. |
| aliases | No | Other words that also find this page in a search; a `[[alias]]` link also leads here. English alternatives a reader might look for, never the page's own title. |
| source | Set by a command | The version of the Chinese text this page translates (a hash). Never written by hand: `npm run wiki:translate -- stamp <file>` sets it. When the Chinese page changes, the build sees that it no longer matches and marks the translation as out of date. |
| object | Only for an English-only page | The id of the game thing the page is about (a person `npc.ilse`, an item `item/weapon/blade/axe`, a monster `actor/creature/beast/wolf`, a boss `alberic`, a location `meadow`, a quest `stew`, a skill branch `swiftness`). Written only on a page about a game thing that has no Chinese file yet. |

The type, the game object and the status (Implemented, Planned, To be designed) are taken from the Chinese page and are not repeated here. Chinese keys (类型, 对象, 摘要…) are also understood, but an English page uses the English ones.

## Links

- `[[Sister Ilse]]`: links to this page.
- `[[Sister Ilse|Ilse]]`: links to this page, shown as "Ilse".
- `[[Controls#Inputs|inputs]]`: links to a section of a page (the section's name is the text after its `##`).
- `[[伊尔丝修女]]`: a Chinese title works too and leads to the English page; so does a Chinese section name. `npm run wiki:translate -- relink <file>` rewrites them into English.
- Category pages are `[[Category:Firstlight Village]]`; the special pages are `[[Special:Recent changes]]`, `[[Special:Stubs]]`, `[[Special:All pages]]`, `[[Special:Random page]]`, `[[Special:Values]]`, `[[Special:Completeness]]` and `[[Special:Search]]`.
- A link to a page that does not exist yet shows in red and is listed on Special:Stubs when the wiki is built, but it is not an error. A link to a section that does not exist is an error.

## Templates

A template is written `{{template name|argument|argument}}`. Arguments may contain links as well. Every template has an English name and a Chinese one; both work in either edition, and the names are not case-sensitive (`{{Infobox}}` is `{{infobox}}` is `{{信息框}}`). The English pages use the English names. Below are all the templates.

### Inline templates

| Written as | Result |
|---|---|
| `{{key|E}}` | A key icon {{key|E}} |
| `{{item|Plank}}`, `{{item|Plank|3}}` | An item's icon with a link, optionally with a count. The argument is the game's name for it (English or Chinese) or its type id. |
| `{{person|Sister Ilse}}` | A portrait with a link |
| `{{monster|wolf}}` | A monster's icon with a link |
| `{{place|Firstlight Village}}` | A link to a location |
| `{{status|burning}}` | A status's name, linked to [[Statuses]] |
| `{{skill|Dash}}` | A skill's icon, linked to its branch |
| `{{value|name}}` | One number from the game, read straight from the code: when the code changes, so does this. The names are the Chinese ones listed in the [[#Value table|value table]] at the end of this page (and on [[Special:Values|Special:Values]]). |

### Banners and quotations

| Written as | Use |
|---|---|
| `{{stub}}` | This page is not finished. It is listed on Special:Stubs. |
| `{{planned}}` | The design is settled, but it is not in the game yet. |
| `{{tbd}}` | Not designed yet; the page records only what is known. |
| `{{dev}}` | A feature that exists only in the development build (such as the developer console). |
| `{{main|Building}}` | "Main article: Building" at the start of a section. |
| `{{see also|Rooms|Stairs}}` | "See also: Rooms, Stairs". |
| `{{quote|text|source}}` | A quotation at the top of a page, such as one of a person's lines. |

### Spoilers

What a person leaves unsaid, and the twists of the story, go in a spoiler block. Readers see it only when they open it.

```
{{spoiler|What she leaves unsaid}}
What is here is folded away by default.
{{/spoiler}}
```

### Data templates

These templates make their content from the game's data, in the game's own English. Never copy their content out as text: a copied number goes stale, the template does not.

**Lists that any page can use**

| Written as | Content |
|---|---|
| `{{item table|weapons}}` | The full table of one kind of item (the regions' own variants are not listed here, but on the base item's page and on [[Regional Goods]]). Kinds: weapons, tools, armor, accessories, food, materials, seeds, structures, furniture, containers, light sources, story items, documents, misc, all |
| `{{resident table}}`, `{{monster table}}`, `{{drop table}}`, `{{boss table}}`, `{{location table}}` | The corresponding full table |
| `{{quest table|main}}` | One of main, side, favor; with no argument, all of them |
| `{{recipe table}}`, `{{building table}}` | Every entry of the crafting panel (C) and of the building panel (B) |
| `{{skill tree|Swiftness}}` | Every skill of one skill branch |
| `{{profession table}}`, `{{boon table}}`, `{{status table}}`, `{{element table}}`, `{{terrain table}}`, `{{substance table}}`, `{{quality table}}`, `{{slot table}}`, `{{crop table}}`, `{{food table}}`, `{{waypoint table}}`, `{{music table}}`, `{{efficiency table}}`, `{{room table}}`, `{{night creature table}}`, `{{legendary arms table}}`, `{{stigma table}}` | The table of that name |
| `{{stall table}}`, `{{stall table|farm}}` | What the stall at [[The Held Ground]] sells and what it pays. Arguments: farm, ranch, fish (one shelf), buy (the three shelves together), sell (what it pays); with no argument, all of them |
| `{{look parts}}`, `{{look parts|hair}}` | The parts of [[Looks|looks]], each with a sample portrait and map sprite. Arguments: hair, face, beard, age, mark, glasses, hat, outfit (one slot); with no argument, all of them |
| `{{regional goods}}`, `{{regional goods|The Pale Fens}}` | Each region's own goods: its named pieces, its local produce, the gear and tools made there (see [[Regional Goods]]). Argument: one region; with no argument, all of them |
| `{{version history}}` | Every change merged into the main branch |

### Navboxes

At the very bottom of a page goes `{{navbox|name}}`, which lists every page of the same group. Names: residents, items, fixtures, monsters, locations, quests (lists the game makes), and the hand-made groups Basics, Interface, Life, Combat, Lore, Design, People, Help (every English page carrying the same name is listed; the Chinese pages write their groups' Chinese names, and `npm run wiki:translate -- relink` turns those into these).

## Fixed structure of each kind of page

Pages of the same kind order their sections the same way, so that readers find the same content in the same place on any page. An English page keeps the sections of its Chinese page, one for one, in the same order; the skeletons below are what they look like in English. When a page is created, the "Edit" or "Translate" button on the site gives this skeleton.

**Person**

```
{{infobox}}
{{quote|A line that is like them|The person's name}}
An opening paragraph: who they are, where they live, what they do.
## Schedule
{{schedule}}
## Relationships
(text){{relationships}}
## Dialogue
{{dialogue}}
## Quests
{{related quests}}
## Portrait
{{portrait}}
## Background
(their place in the story; what they leave unsaid goes in a spoiler block)
## Trivia
## History
{{navbox|residents}}
```

**Item**: infobox → opening paragraph → `## Sources` → `## Uses` → `## Crafting` (only if it can be made) → `## Variants` (only if it comes in materials and qualities) → `## Trivia` → `## History` → navbox.

**Monster, boss**: infobox → opening paragraph → `## Habitat` → `## Behavior` → `## Strategy` → `## Drops` → (a boss has one more section, `## Skills`, placed before Behavior) → `## Background` → `## History` → navbox.

**Location**: infobox → opening paragraph → `## Map` → `## Areas` (the named areas on the map) → `## Residents` → `## Creatures` → `## Items and resources` → `## Connections` → `## Background` → `## History` → navbox.

**Quest**: infobox → opening paragraph → `## Objectives` → `## Walkthrough` (how to complete it, step by step) → `## Stages and journal` (`{{stages}}`: what the journal says at each stage, and when each begins) → `## Rewards` → `## Dialogue` → `## History` → navbox.

**System** (gameplay pages such as Controls and Satiety): opening paragraph → rules (in as many sections as needed; numbers through `{{value}}` or data tables) → `## Tips` (optional) → `## History` → navbox.

**Lore, chapter**: opening paragraph → body → `## Sources` (which original text or which discussion this lore was written in) → navbox. Lore pages record only what has been settled; what has not is marked "to be designed", and nobody invents it for the team.

## The History section

When the game changes something, add a line to the "History" section of its page:

```
## History
- 2026-10-05: The tutorial now teaches one action per lesson; keys not yet taught are locked.
```

On an English page, the History section follows the Chinese one: translate its lines as they are, with the same dates.
