A **Skill Book** is a book that teaches one [[Skills|active skill]]. Each book teaches one skill and is named “Skill Book: skill name”, for example “Skill Book: Whirlwind”. Holding it and right-clicking yourself reads it: once read, you know that skill, and the book is used up. Learning a skill normally costs skill points and asks that you first learn the skills before it; reading costs no points, but you must still have learned the skills before it.

Skill Books are sold at the chapel bookshelf in [[Firstlight Chapel|Firstlight Chapel]], tended by [[Brother Anselm|Brother Anselm]]: there is a book for every active skill, with the profession skills' books on a shelf of their own. None lie on any map, and monsters do not drop them. Even once bought, a book cannot be read while you have not learned the skills before it on the skill tree.

## Uses

{{uses}}

- **Read**: hold it and left-click to use it on yourself (label “Read Skill Book”). When it works: “You read the book and learn so-and-so.” A skill learned this way can go on the skill bar and be used, the same as one learned with points. The book is used up.
- **No points, but the prerequisites**: reading takes no skill points, but the skills before it on the skill tree must be learned first (for example {{skill|Smoke Bomb}} needs {{skill|Shadow Strike}} first, and {{skill|Whirlwind}} needs {{skill|Sweep}} first). Read before that, it says “You must learn so-and-so before so-and-so.” The book stays.
- **Already known**: “You know so-and-so already.” The book stays.
- **Another profession's book**: a profession skill (for example the Mage's {{skill|Fireball}}) can only be read by someone of that profession; anyone who has not chosen it reads “This book is for another profession.” The book stays. The active skills anyone can learn ({{skill|Whirlwind}}, {{skill|Cleave}}, {{skill|Gale Step}}, {{skill|Mend}}) can be read by anyone.
- A Skill Book is made of paper; it can catch fire and burns to [[Ash|Ash]]. The rules do not say what happens when you use it on someone or something else; the world may learn a new answer (see [[The World Learns|the world learns]]).

For the list of active skills, see [[Skills|Skills]] and [[Professions|Professions]].
