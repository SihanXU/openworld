A **Skill Book** is a book that teaches one [[技能|active skill]]. Each book teaches one skill and is named “Skill Book: skill name”, for example “Skill Book: Whirlwind”. Holding it and right-clicking yourself reads it: once read, you know that skill, and the book is used up. Learning a skill normally costs skill points and asks that you first learn the skills before it; reading costs no points, but you must still have learned the skills before it.

Skill Books are sold at the chapel bookshelf in [[初原村礼拜堂|Firstlight Chapel]], tended by [[安塞姆修士|Brother Anselm]]: there is a book for every active skill, with the profession skills' books on a shelf of their own. None lie on any map, and monsters do not drop them. Even once bought, a book cannot be read while you have not learned the skills before it on the skill tree.

## Uses

{{用途}}

- **Read**: hold it and left-click to use it on yourself (label “Read Skill Book”). When it works: “You read the book and learn so-and-so.” A skill learned this way can go on the skill bar and be used, the same as one learned with points. The book is used up.
- **No points, but the prerequisites**: reading takes no skill points, but the skills before it on the skill tree must be learned first (for example {{技能|烟雾弹}} needs {{技能|影袭}} first, and {{技能|旋风斩}} needs {{技能|横扫}} first). Read before that, it says “You must learn so-and-so before so-and-so.” The book stays.
- **Already known**: “You know so-and-so already.” The book stays.
- **Another profession's book**: a profession skill (for example the Mage's {{技能|火球}}) can only be read by someone of that profession; anyone who has not chosen it reads “This book is for another profession.” The book stays. The active skills anyone can learn ({{技能|旋风斩}}, {{技能|重劈}}, {{技能|疾风步}}, {{技能|疗伤}}) can be read by anyone.
- A Skill Book is made of paper; it can catch fire and burns to [[灰烬|Ash]]. The rules do not say what happens when you use it on someone or something else; the world may learn a new answer (see [[世界会学|the world learns]]).

For the list of active skills, see [[技能|Skills]] and [[职业|Professions]].
