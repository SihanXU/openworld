**The OpenWorld Wiki** is the encyclopedia of the game OpenWorld, and at the same time the game's design proposal.

## What it covers

- **Everything in the game.** Every system, every key, every item, every person, every kind of monster, every map and every quest has a page. The sections follow the portal on the [[首页|Main Page]].
- **What is built is described as it is now.** Numbers and names follow the game's code.
- **What is decided but not yet built is marked “Planned”.** For example, buying and selling with villagers (see [[金钱#还没有的|Money]]).
- **What is not yet designed is marked “To be designed”.** For example, the chapters of the Second to the Fifth Seal (from [[第二章|Chapter 2]] on). Only what has been settled is recorded; the wiki does not fill in the setting on the team's behalf.
- **The lore** follows “The Church of the Five Sufferings: Setting and Main Story”; the original text is at [[世界观原文]].

## Where the content comes from

| Content | Source |
|---|---|
| Infoboxes, tables, schedules, dialogue, recipes, drops, maps, boss skills | Read from the game's code at build time (`games/openworld/content`, `games/openworld/tools/src/demo`); see [[格式手册#数据模板|data templates]] |
| Numbers (`{{数值|…}}`) | As above; see [[特殊：数值]] |
| Body text: how the rules work, how to play, the setting | Written by hand by the project team, based on the code, design discussions and design documents |
| Words that exist only in English in the code and are never seen in the game | `wiki/译名.json` in the repository |

When the game's code changes, every data table follows at the next build; the body text has to be changed by a person.

## How it is updated

1. The source files are in the `wiki/` directory of the GitHub repository [SihanXU/symbolic-world](https://github.com/SihanXU/symbolic-world). Everyone on the project team can edit them; see [[编辑入门]].
2. On every commit or pull request, the repository's automatic checks build the whole wiki: if a link or template is wrong, or something in the game has no page ([[特殊：完备性]]), the check fails.
3. Once a change is merged into the main line, the server checks once a minute and rebuilds when there is a new commit; the site updates a minute or two later. If the build fails, the site keeps the previous version.

## Conventions

This site's page structure and editing conventions follow the [official Chinese Stardew Valley Wiki](https://zh.stardewvalleywiki.com/): a fixed infobox and section order for each kind of page, a navigation box at the bottom, categories, the “stub” marker, and a “History” section on every page. See the [[格式手册]] and the [[风格指南]] for details.

## What is not included

- Research and the paper (the modder service's self-improvement and so on); they are not part of the game.
- Internal arrangements of the collaborators and the project team.
