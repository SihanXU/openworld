This page lists OpenWorld's progress by system. **Implemented**: in the game now; **Planned**: designed, not yet built; **To be designed**: no design yet. For the details of each item, see its page. The merge record is at [[版本历史]].

## World and rules

| Item | Status | Notes |
|---|---|---|
| The event model: the only AI interface is the outcome of an event | Implemented | 2026-10-02. See [[世界会学]] |
| A learned rule belongs to one kind of thing only and fills one gap only | Implemented | 2026-10-09. Other kinds each ask their own question, and cases left unanswered are asked later; rules once written for a whole class are no longer used. See [[世界会学#一条规则管一种东西的一处空缺|The World Learns]] |
| G1: the general cases of the base rules | Implemented | 2026-10-09. Things handed to creatures (fiber ties them up, food is swallowed), swings into empty cells are all blunt blows, wild creatures bite a reaching hand, terrain is only touched, warming up beside a lit fire, ore smelted into ingots in a forge, a collapsed Lumi waiting where she fell. See [[世界会学#游戏自己会的通用情形|The general cases the game knows by itself]] |
| World model v4: everything is a thing, only things and the clock, durability, makeup, stages, spaces, rooms, two levels of map | Implemented | 2026-10-04; all ten steps (W1–W10) done. See [[耐久与破坏]], [[房间]], [[世界地图]] |
| Four inputs: E, G, left click, right click, with reach written in data | Implemented | 2026-10-05; set as four inputs on 2026-10-21 (picking up loose things goes to {{键|E}}, using a held thing on something goes to the right click). See [[操作]] |
| Key descriptions follow the target and the item; AI patches write descriptions too | Implemented | 2026-10-05 |
| Difficulty and death | Implemented | 2026-10-05. See [[难度]] |
| Multi-storey buildings: each storey builds only its own level, the ceiling excepted; stairs; 3/4 perspective | Implemented | 2026-10-05. See [[楼层]] |
| Two speeds of satiety | Implemented | 2026-10-06. See [[饱食度]] |
| Layers and occlusion (floors under standing things, things that hide people become translucent) | Implemented | 2026-10-07 |
| Digging into mountains (the ground below made into things) | To be designed | At present the ground itself cannot be broken |
| Food spoiling, iron rusting, campfires burning out, eggs hatching | Planned | The “stages” mechanism already supports it; no content yet |
| Floors laid on water as bridges | Planned | At present a plank put into water can become a wooden bridge tile |
| Encounters on the world map | To be designed | |
