The **Threadbook** records everything the world has learned. Each time the world learns a new rule, it is said that “a new thread is woven”. Press {{键|J}} to open the [[图鉴|codex]]; its last tab is the Threadbook.

After you first do something the world has never seen beside the [[五伤路碑|five-wound shrine stone]] at [[山脚]], [[露米]] says: “What it learns is kept in the Threadbook — press J.”

## A thread

The Threadbook lists every thread from newest to oldest. Each entry gives:

- what the rule says: a one-line English description the AI attaches when it writes the rule. When the game is set to Chinese, a line in Chinese first says what the thread does (the rule's own wording, such as the line in the action prompt), with the English description below it in small gray text; when the rule has no wording of its own, only the English description is shown;
- **woven by**: “you”, “the world” or “another player (the shared library)”;
- the date it was woven (the real-world date).

| Woven by | Meaning |
|---|---|
| You | This rule was learned because you did something with your own hands in this game (pressed a key marked “?”) |
| The world | This rule came from something that happened in the world by itself, such as fire reaching something that had never burned before |
| Another player (the shared library) | This rule was synced from the shared library; someone else's action taught it to the world |

While there are no new threads yet, the page reads: “No threads yet. Try something the world has never seen.”

## Where threads come from

When the world has not yet defined the outcome of an action and the game is connected to an AI, the AI writes a rule for the outcome when this one kind of thing meets this event, and once it passes the checks it is woven into the world. When the same kind of thing meets the same event again, the AI is not asked; the thread decides. A different kind meeting the same event needs a thread of its own. The lower left of the screen shows “✦ A new thread is woven”, followed by the thread's wording. See [[世界会学]] for details.

- The threads in the Threadbook belong to the **shared library**, not to any one save. Every save reads the same threads, and starting a new game does not clear them.
- Every player connected to the same AI service shares this library: what others teach the world, your world learns too. The library syncs about every 15 seconds.
- A thread only fills a gap; it never changes behavior that is already defined.
- A thread governs only the one place it was asked about. The cases it did not answer are asked when they come up, and the new thread woven then attaches to an open branch in the same place; the earlier thread stays as it was.
- Threads woven before 2026-10-09 that were written for a whole class of things are no longer used: they fail the checks when read in and are dropped, so they no longer appear in the Threadbook (see [[世界会学#旧的线|Old threads]]).

## Tips

- To see what the world has learned, leaf through the Threadbook. It is also a source of ideas: what others have tried, and what you could still try.
- An empty Threadbook means this world has not yet been taught anything. Hold something and right-click the things around you, looking for actions marked “?”.

## History

- 2026-10-01: The Threadbook was added, recording every rule the world learns and who taught it.
- 2026-10-06: The Threadbook became a page of the codex ({{键|J}}).
- 2026-10-08: In Chinese, each thread shows its Chinese wording first; threads synced from the shared library are woven by “another player (the shared library)”.
- 2026-10-09: Each thread belongs to one kind of thing only and fills one gap only; the old threads written for a whole class are no longer listed.
- 2026-10-21: The controls were set as four inputs: using a held thing on something moved to the right click (the left click is the held thing's own use: a tool or weapon is swung, anything else is used on yourself), and picking up loose things moved to {{键|E}} (see [[操作]]).
