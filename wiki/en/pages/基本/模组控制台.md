The **Mod Console** is a window for developers, present only in the development build and not in the released game. It lists every [[世界会学|undefined event]] the world has met, shows the request the AI would receive, and lets a person write a patch by hand. A hand-written patch goes through the same checking, applying and saving as one written by the AI, so you can use it to teach the world new things even without an AI connected.

## Opening it

- Press {{键|`}} (the key to the left of 1) to open or close it.
- Or click “Mod Console (dev)” in the [[选项]].
- Click ✕ or press {{键|Esc}} to close it. Time pauses while it is open.

The right side of the top bar shows the AI service's status: “● Modder: model name” when connected, “○ No modder: patch by hand” when not.

## The four tabs

### Undefined

- On the left, the undefined events the world has met, newest first, each preceded by a status: pending (waiting), patched (learned), fallback (handled by default), rejected (the patch was refused).
- Choose one and the right side shows what event it is, the tick it happened on, the map, the hour, and the full request sent to the AI.
- Below is a text box for writing a patch:
  - **Fill template**: fills in a starting point for a patch: the host is the kind of thing that hosted this event (its exact type), the event kind, the hole (`hole`) and the place (`at`) filled in from this event, plus one visible result, a few notes to fill in, and this event as a test;
  - **Copy as LLM prompt**: copies the request, together with the spec, as a prompt you can hand straight to a large language model;
  - **Nothing happens**: appears only while the event is still waiting, and applies the default directly;
  - **Validate & apply**: checks the patch, and if it passes it takes effect at once. The result shows “✓ Validated and applied”, or lists the errors and warnings.

A hand-written patch, like one written by the AI, belongs to a single kind of thing and fills a single hole (see [[世界会学#一条规则管一种东西的一处空缺|one rule for one hole of one kind of thing]]):

- The host must be exactly `{"type": 种类}` (a kind's type id); it cannot be a tag or a whole class; cases go in the rule's tree.
- `on` must be an exact event kind, not a broad class.
- `hole` is required (which hole it fills); `at` is where it attaches in this kind's tree, on which open branch (empty for the first answer).
- No `inherit`; every `if` needs an `else`; a case it does not answer is written `{"undefined": true}`, left open to be asked later. At least one place must give a result.
- When submitted against the chosen event, the host, event kind, `hole` and `at` are filled in by the game from that event, and branches written as `inherit` or missing an `else` are turned into open leaves, so by hand you need only write the tree.

### Rule library

Shows the rule library's version number, the number of base rules, the number of patches and the number of rules for each event kind, and below lists the patches one by one: number, event kind, author and time, each with a remove button to delete it.

### ModSpec

The full specification the AI follows when it writes a patch: which events, effects, statuses, terrains and item kinds exist, and the guidelines for writing rules. Copy JSON copies it.

### World

Debugging tools, plus the world's statistics and performance figures (the numbers of maps, people, creatures and items, time per tick, number of entities, maps loaded, frame rate):

| Tool | What it does |
|---|---|
| Give | Gives yourself one thing by its item kind's id (such as `item/material/iron_ore`); the input box suggests the ids available |
| Teleport | Teleports to a coordinate on a map (the current map if left blank) |
| Emberfall, by the lit forge | Teleports straight to the lit forge in [[余烬镇]] |
| Set hour | Sets the clock to a given hour |
| Summon the White Knight | Summons [[白骑士·阿尔贝里克]] on [[东大路]], for testing the boss fight again and again |

## Other development features

- **Invulnerability**: in the development build, type `lsw.god()` in the browser console to toggle invulnerability, or add `?god=1` to the address; when it is on, the message “Invulnerable (dev).” appears.
- **Choosing the AI service**: add `?modder=地址` (an address) to the URL to connect to another AI service, or `?modder=off` to connect to none. The development build connects to the service on this machine by default.
- **Prefetch**: with `?prefetch=1` added to the address, resting the mouse on an act with a “?” for a moment makes the game ask the AI ahead of time. It is off by default, because it spends model calls on acts the player never actually performs.
- **Boss · test stage**: remove the `?challenge=1` parameter from the page where the title page's “Boss Challenge” lives, and you have the bosses' test stage for development. See [[首领挑战]].
- **Pruning the shared rule library**: on the command line, `npm run modder -- library prune` lists and withdraws the patches that no longer pass the checks, such as patches written for a whole class before 2026-10-09, or patches whose hole the game's rules have since changed; the AI service also prunes this way every time it starts. `npm run modder -- library` lists every patch, and `npm run modder -- library remove <编号>` deletes one.
