How it works

Asked once

Most of what you do already has a rule and the game just runs it. Only when you try something no rule covers does the game ask a language model, and the new rule it writes back is checked, added to the library and simply run for whoever meets the same thing after.

A world that learns as it goes

OpenWorld is a role-playing world whose entire state and rule set are represented as code. When play reaches an interaction or an item that no author defined, a language model supplies it once, and every comparable case thereafter uses the result.
